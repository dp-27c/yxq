# 题目 11：环廊警报

## 题目描述

一条环形走廊上有 $n$ 块电子屏，沿顺时针方向依次编号为 $1,2,\ldots,n$，第 $n$ 块的下一块是第 $1$ 块。每块电子屏都需要显示一个字符 `0` 或 `1`。

警报系统保存了一个非空字符串 $p$，长度为 $m$。从任意一块电子屏出发，沿顺时针方向连续读取 $m$ 次显示内容，每次读取一块屏幕，然后移到下一块。若读出的字符串恰好等于 $p$，就会触发警报。

当 $m>n$ 时，读取过程会绕过起点，甚至绕行多圈。同一块电子屏可能被读取多次，每次读取到的都是它固定显示的字符。例如，两块电子屏依次显示 `0`、`1` 时，从第 $1$ 块开始连续读取五次，会得到 `01010`。

请计算有多少种显示方案不会触发警报，也就是无论从哪一块电子屏开始读取，都不会得到字符串 $p$。答案对 $998244353$ 取模。

所有电子屏都有固定编号。两个方案不同，当且仅当某一块编号相同的电子屏显示的字符不同；旋转后能够重合的两个方案仍然可能是不同方案。

## 输入格式

第一行包含一个整数 $n$，表示电子屏数量。

第二行包含一个非空字符串 $p$，表示会触发警报的字符串。

## 输出格式

输出一个整数，表示不会触发警报的显示方案数量对 $998244353$ 取模后的结果。

## 数据范围与约定

- $1\le n\le10^{18}$。
- $1\le |p|\le60$。
- 字符串 $p$ 仅包含字符 `0` 和 `1`。
- 每块电子屏恰好显示一个字符，且在所有读取过程中保持不变。
- 警报系统会考虑全部 $n$ 个出发位置，始终沿顺时针方向读取，不进行逆时针读取。
- 读取过程允许重复经过同一块屏幕，不要求 $|p|\le n$。
- 不同出发位置对应的读取片段允许重叠。
- 不存在将两个旋转方案合并计数的操作。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
4
00
```

**输出：**

```text
7
```

## 样例 1 解释

按照编号 $1,2,3,4$ 依次写出各屏幕显示的字符，七种合法方案为 `1111`、`0111`、`1011`、`1101`、`1110`、`0101`、`1010`。

方案 `0110` 不合法：从第 $4$ 块屏幕开始读取，会先读到第 $4$ 块的 `0`，再读到第 $1$ 块的 `0`，从而触发警报。

`0101` 和 `1010` 是两个不同的合法方案，因为它们在同一编号的屏幕上显示的字符不同。

## 样例 2

**输入：**

```text
2
010
```

**输出：**

```text
2
```

## 样例 2 解释

合法方案为 `00` 和 `11`。

方案 `01` 从第 $1$ 块屏幕开始读取三个字符，就会得到 `010`；方案 `10` 从第 $2$ 块屏幕开始读取三个字符，也会得到 `010`。虽然触发字符串比环上屏幕数量更长，这两种方案仍然会触发警报。
