# 题目 1：三路核验

## 题目描述

有 $n$ 份档案，编号为 $1,2,\ldots,n$。第 $i$ 份档案的代号是非空字符串 $s_i$，只包含小写英文字母。不同档案允许使用相同的代号。

核验器每次选择三份不同的档案，同时从左到右读取它们的代号。第 $t$ 轮读取三个代号各自的第 $t$ 个字符；如果某个代号的长度小于 $t$，则该代号在这一轮以及之后的轮次中都读出特殊符号 `#`。符号 `#` 与所有英文字母都不同。

只要某一轮的三个读数不全相同，核验器就立即停止，不再读取后面的字符。若停止时三个读数两两不同，则这三份档案通过核验；若其中仍有两个读数相同，则不能通过核验。若三个代号始终读出相同的符号，也不能通过核验。

请统计有多少种选择三份不同档案的方式能够通过核验。

## 输入格式

第一行包含一个整数 $n$。

接下来 $n$ 行，第 $i$ 行包含一个字符串 $s_i$，表示第 $i$ 份档案的代号。

## 输出格式

输出一个整数，表示能够通过核验的三份档案选择数量。答案不取模。

## 数据范围与约定

- $1\le n\le2\times10^5$。
- 每个 $s_i$ 非空，只包含小写英文字母。
- 所有代号的长度之和不超过 $4\times10^5$。
- 档案按编号区分，即使代号相同，也仍然是不同档案。
- 每种选择只由三个档案编号构成的集合决定，不区分选择顺序。
- 一份档案不能在同一次核验中被选择多次。
- 核验器必须在三个读数第一次不全相同的轮次停止，不能跳过这一轮等待后面出现三个不同读数。
- 字符下标从 $1$ 开始；符号 `#` 不会出现在输入的代号中。
- 不足三份档案时，答案为 $0$。
- 答案可能超过 $32$ 位有符号整数范围。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
6
a
ab
ac
b
c
b
```

**输出：**

```text
7
```

## 样例 1 解释

从档案 $1,2,3$ 中选择一份，从档案 $4,6$ 中选择一份，再选择档案 $5$，共有六种选择。它们在第一轮的三个读数就是 `a`、`b`、`c`，因此通过核验。

选择档案 $1,2,3$ 时，第一轮都读出 `a`，第二轮分别读出 `#`、`b`、`c`，也能通过核验。

没有其他选择能够通过核验，所以答案为 $7$。档案 $4$ 和档案 $6$ 的代号虽然相同，选择不同编号仍分别计数。

## 样例 2

**输入：**

```text
4
aaa
aaa
aa
a
```

**输出：**

```text
0
```

## 样例 2 解释

这些代号只可能读出 `a` 或 `#`。选择任意三份档案，都不可能在停止时得到三个两两不同的读数，因此答案为 $0$。
