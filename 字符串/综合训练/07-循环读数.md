# 题目 7：循环读数

## 题目描述

一份原始记录是长度为 $n$ 的字符串 $s$，字符只包含小写英文字母。字符位置从 $1$ 到 $n$ 编号。

读数器可以选择记录中的一段连续字符，并将这段字符从左到右连续读若干遍。若选中的字符串为 $A$，读取次数为正整数 $u$，得到的完整读数记为 $A^u$，表示将 $u$ 份 $A$ 依次连接。例如，`ab` 读取三遍得到 `ababab`。

有 $q$ 次独立询问。每次给出两个区间 $[l_1,r_1]$、$[l_2,r_2]$ 和各自的读取次数 $u,v$。令

$$
A=s_{l_1}s_{l_1+1}\cdots s_{r_1},\qquad
B=s_{l_2}s_{l_2+1}\cdots s_{r_2}.
$$

请比较两个完整读数 $A^u$ 与 $B^v$ 的字典序。

字母顺序为 `a`、`b`、……、`z`。比较两个字符串时，从左到右找到第一个不同的字符，字符较小的一方字典序较小；若不存在这样的字符，则较短的字符串字典序较小；长度也相同时，两个字符串相等。

## 输入格式

第一行包含两个整数 $n,q$。

第二行包含字符串 $s$。

接下来 $q$ 行，每行包含六个整数 $l_1,r_1,u,l_2,r_2,v$，描述一次询问。

## 输出格式

对每次询问输出一行：

- 若 $A^u$ 的字典序小于 $B^v$，输出 `-1`。
- 若两个完整读数相等，输出 `0`。
- 若 $A^u$ 的字典序大于 $B^v$，输出 `1`。

## 数据范围与约定

- $1\le n,q\le2\times10^5$。
- $s$ 的长度恰好为 $n$，且仅包含小写英文字母。
- 每次询问满足 $1\le l_1\le r_1\le n$、$1\le l_2\le r_2\le n$。
- $1\le u,v\le10^{12}$。
- 所选区间都非空，且包含左右端点。两个区间可以重叠，也可以完全相同。
- 每遍都从所选区间的第一个字符开始，并完整读到最后一个字符，然后才开始下一遍。
- 每次询问都基于同一份原始记录，不会修改 $s$，也不会影响其他询问。
- 比较的是完整读数中的字符，与字符来自原记录中的哪个位置无关。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
5 4
ababa
1 2 1 3 5 1
1 2 2 3 5 1
1 2 3 3 5 2
1 2 2 1 4 1
```

**输出：**

```text
-1
1
1
0
```

## 样例 1 解释

四次询问比较的完整读数依次为：

- `ab` 与 `aba`。前者是后者的较短前缀，因此输出 `-1`。
- `abab` 与 `aba`。后者是前者的较短前缀，因此输出 `1`。
- `ababab` 与 `abaaba`。第 $4$ 个字符分别为 `b` 和 `a`，因此输出 `1`。
- `abab` 与 `abab`。两个完整读数相等，因此输出 `0`。

## 样例 2

**输入：**

```text
3 3
aaa
1 1 1000000000000 1 3 333333333333
1 2 500000000000 2 2 1000000000000
1 3 1 1 1 4
```

**输出：**

```text
1
0
-1
```

## 样例 2 解释

所有读数都只包含字符 `a`。

第一次询问中，两边的完整长度分别为 $10^{12}$ 和 $999999999999$，前者较长。第二次询问中，两边的完整长度都是 $10^{12}$，因此相等。第三次询问比较 `aaa` 与 `aaaa`，前者较短。
