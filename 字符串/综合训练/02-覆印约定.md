# 题目 2：覆印约定

## 题目描述

印刷车间准备制作一条长度为 $N$ 的字符带，每个位置都必须印上一个小写英文字母，位置从左到右编号为 $1,2,\ldots,N$。

车间有一个非空的模板字符串 $P$，以及 $q$ 条覆印约定。第 $i$ 条约定给出两个整数 $s_i,\ell_i$，要求字符带从位置 $s_i$ 开始的连续 $\ell_i$ 个字符，依次等于模板 $P$ 的前 $\ell_i$ 个字符。

不同约定可以指定不同的长度，也可以具有相同的起点。它们涉及的区段允许重叠或互相包含；同一个位置只有一个最终字符，必须同时满足所有涉及它的约定。

没有被约定限制的位置可以印上任意小写英文字母。没有列出的区段不受额外限制，即使其中也出现了模板的某个前缀，仍然是合法的。

请计算满足全部约定的不同字符带数量，答案对 $998244353$ 取模。

## 输入格式

第一行包含两个整数 $N,q$。

第二行包含模板字符串 $P$。

接下来 $q$ 行，第 $i$ 行包含两个整数 $s_i,\ell_i$，描述第 $i$ 条约定。

## 输出格式

输出一个整数，表示合法字符带数量对 $998244353$ 取模后的结果。若所有约定无法同时满足，输出 $0$。

## 数据范围与约定

- $1\le N\le10^{18}$，$0\le q\le2\times10^5$。
- $1\le |P|\le2\times10^5$，$P$ 仅包含小写英文字母。
- $1\le s_i\le N$，$1\le\ell_i\le|P|$，且 $s_i+\ell_i-1\le N$。
- 约定按任意顺序给出，允许相同起点，也允许完全相同的约定重复出现。
- 所有约定都必须满足，不存在后写入的约定覆盖此前约定的规则。
- 两条字符带不同，当且仅当至少一个位置的字符不同；重复约定不会使同一条字符带被重复计数。
- $q=0$ 时，没有覆印约定，也没有对应的输入行。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
10 3
ababa
2 5
4 3
8 2
```

**输出：**

```text
17576
```

## 样例 1 解释

第一条约定要求位置 $2$ 到 $6$ 依次为 `ababa`。第二条约定要求位置 $4$ 到 $6$ 为 `aba`，与第一条约定一致。第三条约定要求位置 $8,9$ 为 `ab`。

因此位置 $1,7,10$ 可以分别选择任意小写英文字母，其余位置都已确定，共有 $26^3=17576$ 条合法字符带。

## 样例 2

**输入：**

```text
6 3
aaab
1 4
2 1
3 2
```

**输出：**

```text
0
```

## 样例 2 解释

第一条约定要求位置 $4$ 为 `b`，第三条约定却要求位置 $4$ 为 `a`。这两个要求无法同时满足，因此不存在合法字符带。
