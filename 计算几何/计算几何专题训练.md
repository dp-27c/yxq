### A. 矩形的四个顶点

**预计难度：CF 1700**

**题目来源：原创训练设计 / 经典矩形对角线计数模型**

#### 题目描述

平面上有 $n$ 个互不相同的整点。请计算其中有多少个四点集合，恰好可以作为一个面积大于 $0$ 的矩形的四个顶点。

矩形的边可以与坐标轴形成任意角度。只要选出的四点集合不同，就视为不同的矩形；同一组四点无论按何种顺序列出，都只计数一次。

#### 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行两个整数 $x_i,y_i$，表示一个点的坐标。

#### 输出格式

输出一个整数，表示符合条件的矩形数量。

#### 数据范围

$1\le n\le2000$，$-10^6\le x_i,y_i\le10^6$。

输入点两两不同。允许多个点共线。

本题训练资源约定：时间限制 $3$ 秒，内存限制 $256$ MiB。

#### 输入样例 1

```text
9
0 0
0 1
0 2
1 0
1 1
1 2
2 0
2 1
2 2
```

#### 输出样例 1

```text
10
```

#### 样例解释 1

有 $9$ 个边平行于坐标轴的矩形。此外，$(0,1),(1,0),(2,1),(1,2)$ 构成一个旋转了的正方形，因此答案为 $10$。

#### 输入样例 2

```text
4
-2 -2
-1 -1
0 0
3 3
```

#### 输出样例 2

```text
0
```

#### 样例解释 2

四个点共线，不能构成面积大于 $0$ 的矩形。

### B. 穿过所有线段

**预计难度：CF 1800**

**题目来源：经典模型教学重述 / POJ / [3304 — Segments](http://poj.org/problem?id=3304)。** 题号、题名及公共截线模型有公开资料佐证，未取得原题完整题面。本训练采用单组整数输入，输入输出、范围与样例以本文为准。

#### 题目描述

平面上给定 $n$ 条闭线段，第 $i$ 条线段的两个端点为 $A_i$ 和 $B_i$。

请判断是否存在一条无限延伸的直线，与每一条给定线段都有至少一个公共点。

经过线段端点、与线段重合，都视为与该线段有公共点。不同线段之间可以相交、重叠或共用端点。

#### 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行四个整数 $x_{i,1},y_{i,1},x_{i,2},y_{i,2}$，依次表示 $A_i$ 和 $B_i$ 的坐标。

#### 输出格式

如果存在符合条件的直线，输出 `YES`；否则输出 `NO`。

#### 数据范围

$1\le n\le150$。所有坐标均为整数，绝对值不超过 $10^6$。

每一条线段的两个端点不同。允许不同线段完全相同。

本题采用上述单组整数输入规格。训练资源约定：时间限制 $3$ 秒，内存限制 $256$ MiB。

#### 输入样例 1

```text
3
0 0 1 0
1 1 2 1
4 2 5 2
```

#### 输出样例 1

```text
YES
```

#### 样例解释 1

直线 $x=2y$ 分别在线段端点 $(0,0)$、$(2,1)$、$(4,2)$ 处与三条线段相交。端点处的接触符合要求。

#### 输入样例 2

```text
3
0 0 1 0
4 1 5 1
0 2 1 2
```

#### 输出样例 2

```text
NO
```

#### 样例解释 2

任意一条同时经过第一条和第三条线段的直线，在 $y=1$ 处的交点横坐标都在 $[0,1]$ 内，因此不能经过第二条线段。

### C. 整点多边形的切分

**预计难度：CF 1900**

**题目来源：原创训练设计 / 整点几何与凸多边形最优三角剖分**

#### 题目描述

给定一个严格凸的多边形，其 $n$ 个顶点均为整点，按逆时针顺序编号为 $1,2,\ldots,n$。整点是指横坐标和纵坐标均为整数的点。

你需要添加 $n-3$ 条多边形对角线，将多边形恰好分成 $n-2$ 个三角形。每条对角线的两端必须是原多边形的两个不相邻顶点；对角线之间只能在公共端点处相交。不能添加新的剖分顶点。

对于得到的每一个三角形，计算严格位于其内部的整点数量，再将这些数量相加，作为本次切分的代价。位于三角形边界上的整点不计入该三角形，因此位于所添加对角线上的整点不计入任何三角形的内部。

请计算所有合法切分方案中的最小代价。当 $n=3$ 时，不添加对角线，整个多边形就是唯一的三角形。

#### 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行两个整数 $x_i,y_i$，按逆时针顺序给出多边形各顶点。

#### 输出格式

输出一个整数，表示最小切分代价。

#### 数据范围

$3\le n\le300$，$-10^6\le x_i,y_i\le10^6$。

保证所有顶点两两不同，给出的多边形严格凸，且顶点顺序为逆时针。严格凸意味着所有内角都小于 $180^\circ$。

本题训练资源约定：时间限制 $3$ 秒，内存限制 $256$ MiB。

#### 输入样例 1

```text
4
0 0
4 0
4 3
0 2
```

#### 输出样例 1

```text
5
```

#### 样例解释 1

连接顶点 $2$ 和 $4$，得到的两个三角形内部整点数量分别为 $1$ 和 $4$，总代价为 $5$。连接顶点 $1$ 和 $3$ 时总代价为 $6$，所以最小值为 $5$。整点 $(2,1)$ 位于所选对角线上，不计入任何三角形的内部。

#### 输入样例 2

```text
3
0 0
2 0
0 2
```

#### 输出样例 2

```text
0
```

#### 样例解释 2

不需要添加对角线。点 $(1,1)$ 位于三角形边界上，其他整点也均不在严格内部，因此代价为 $0$。

### D. 镜面台球的第一个角

**预计难度：CF 1900**

**题目来源：教学改编 / Codeforces / Billiard / [982E](https://codeforces.com/problemset/problem/982/E)**（本训练将起点限制在矩形严格内部，将两个速度分量限制为 $\pm1$，并增加首次到角时间的输出）

#### 题目描述

一张矩形台球桌的四个角为 $(0,0)$、$(W,0)$、$(0,H)$、$(W,H)$。把球视为一个没有大小的点，最初位于桌面内部的 $(x,y)$，速度为 $(v_x,v_y)$，其中两个速度分量分别为 $1$ 或 $-1$。

球始终匀速运动。当它碰到竖直桌边时，横向速度分量立即变号；碰到水平桌边时，纵向速度分量立即变号。反射不消耗时间，也不改变速度分量的绝对值。

如果球到达任意一个角，就立即停止。请判断球是否会到达某个角。如果会，求第一次到角的时间以及那个角的坐标；否则报告无解。时间从球开始运动时的 $0$ 计起。

#### 输入格式

一行六个整数 $W,H,x,y,v_x,v_y$。

#### 输出格式

如果球永远不会到达任何一个角，输出 `-1`。

否则输出三个整数 $t,X,Y$，依次表示第一次到角的时间及该角的坐标。题目给定的整数坐标与速度保证：如果存在这样的时间，它一定是正整数。

#### 数据范围

$2\le W,H\le10^9$，$1\le x<W$，$1\le y<H$，$v_x,v_y\in\{-1,1\}$。

所有输入均为整数。

本题训练资源约定：时间限制 $1$ 秒，内存限制 $256$ MiB。

#### 输入样例 1

```text
6 4 1 1 -1 1
```

#### 输出样例 1

```text
7 6 0
```

#### 样例解释 1

球在时刻 $1$ 到达 $(0,2)$ 并反射，在时刻 $3$ 到达 $(2,4)$ 并再次反射，随后在时刻 $7$ 第一次到达角 $(6,0)$。

#### 输入样例 2

```text
6 4 1 2 1 1
```

#### 输出样例 2

```text
-1
```

#### 样例解释 2

球到达竖直桌边的时刻均为奇数，到达水平桌边的时刻均为偶数，因此不会同时到达两种桌边，也就永远不会到达角。

### E. 方向冠军概率

**预计难度：CF 1900**

**题目来源：经典凸包概率模型的训练表述；相关题目为 AtCoder / [AGC021 B — Holes](https://atcoder.jp/contests/agc021/tasks/agc021_b)。** 本题独立定义均匀随机方向下的线性评分实验、输入范围及样例，不声称模型首创。已核对相关题目的第三方题意摘要和解法记录，未取得官方题面全文。

#### 题目描述

平面上有 $n$ 个互不重合的站点，第 $i$ 个站点的位置为 $(x_i,y_i)$。

从区间 $[0,2\pi)$ 中连续均匀随机地选取一个角度 $\theta$。站点 $i$ 在这个方向上的得分定义为

$$
s_i=x_i\cos\theta+y_i\sin\theta.
$$

如果某个站点的得分严格大于其余所有站点的得分，就称它是这一方向的冠军。如果最高分由多个站点共同取得，则这一方向没有冠军。只有一个站点时，它在所有方向上都是冠军。

请对每个站点求出它成为冠军的概率。

#### 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行两个整数 $x_i,y_i$，按编号顺序给出站点坐标。

#### 输出格式

输出 $n$ 行，第 $i$ 行输出站点 $i$ 成为冠军的概率。

设正确答案为 $a$，选手输出为 $b$，只要满足

$$
|a-b|\le10^{-6}\max(1,|a|)
$$

就视为正确。

#### 数据范围

- $1\le n\le2\times10^5$。
- $-10^9\le x_i,y_i\le10^9$。
- 站点坐标两两不同；允许多个站点共线，也允许所有站点共线。
- 输入为单组数据。

#### 输入样例 1

```text
5
0 0
4 0
4 4
0 4
2 2
```

#### 输出样例 1

```text
0.2500000000
0.2500000000
0.2500000000
0.2500000000
0.0000000000
```

#### 样例解释 1

四个角上的站点地位对称，各自在四分之一的方向范围内独占最高分。中心站点不会成为冠军。

#### 输入样例 2

```text
4
-2 0
-1 0
3 0
0 0
```

#### 输出样例 2

```text
0.5000000000
0.0000000000
0.5000000000
0.0000000000
```

#### 样例解释 2

当 $\cos\theta<0$ 时，站点 $1$ 获胜；当 $\cos\theta>0$ 时，站点 $3$ 获胜。恰有 $\cos\theta=0$ 的两个方向没有冠军，但有限个角度不影响连续均匀分布下的概率。

### F. 凸域通行证

**预计难度：CF 1800**

**题目来源：经典凸多边形查询模型的训练重述；相关题目为 AtCoder / [ABC296 G — Polygon and Points](https://atcoder.jp/contests/abc296/tasks/abc296_g)（2023）。** 已核对题号、题名及公开实现，未取得官方题面全文。本文独立规定题意、输入约束并编写样例，不作为参考原题的完整翻译。

#### 题目描述

给定一个具有 $n$ 个顶点的严格凸多边形。顶点按沿边界逆时针行走的顺序给出。这里的严格凸多边形指：多边形没有自交，每个内角都严格小于 $180^\circ$。

有 $q$ 个互相独立的查询，每个查询给出平面上的一个点 $P$。请判断它位于多边形的哪个位置：

- 严格位于内部，输出 `IN`。
- 位于边界上，输出 `ON`。边界包括全部边和顶点。
- 位于外部，输出 `OUT`。

#### 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行两个整数 $x_i,y_i$，依次给出多边形的顶点。

接下来一行一个整数 $q$。

接下来 $q$ 行，每行两个整数 $a_j,b_j$，表示一个查询点。

#### 输出格式

对每个查询输出一行，内容为 `IN`、`ON` 或 `OUT`。

#### 数据范围

- $3\le n\le2\times10^5$，$1\le q\le2\times10^5$。
- 所有输入坐标均为整数，绝对值不超过 $10^9$。
- 多边形的顶点互不相同，并保证构成严格凸多边形；第一个顶点不在输入末尾重复。
- 查询点允许重复，也允许与顶点重合或位于边上。
- 输入为单组数据。

#### 输入样例 1

```text
3
0 0
6 0
0 6
6
1 1
3 3
4 4
0 0
2 0
-1 1
```

#### 输出样例 1

```text
IN
ON
OUT
ON
ON
OUT
```

#### 样例解释 1

点 $(3,3)$ 位于斜边上；点 $(0,0)$ 是顶点，也属于边界。点 $(4,4)$ 位于这条斜边外侧。

#### 输入样例 2

```text
5
0 0
4 0
6 2
3 5
0 3
5
3 1
9 3
4 4
0 2
-1 1
```

#### 输出样例 2

```text
IN
OUT
ON
ON
OUT
```

#### 样例解释 2

点 $(3,1)$ 位于连接顶点 $(0,0)$ 与 $(6,2)$ 的线段内部，但这条线段是多边形的对角线，所以该点严格位于多边形内部。点 $(4,4)$ 位于连接 $(6,2)$ 与 $(3,5)$ 的边上。

### G. 包围信标

**预计难度：CF 2000**

**题目来源：原创训练设计，采用“半圆覆盖与包含指定点的三角形计数”这一经典模型，不声称模型首创。**

#### 题目描述

平面上有一个位于原点 $O=(0,0)$ 的信标，以及 $n$ 个互不相同的观测站。第 $i$ 个观测站的位置为 $P_i=(x_i,y_i)$。

你需要选择三个不同的观测站，使它们构成一个非退化三角形，并且信标严格位于这个三角形的内部。位于边上或顶点上的信标不算被包围。

保证所有观测站都不在原点，并且经过原点的任意一条直线上至多有一个观测站。除此之外，允许三个或更多观测站共线。

请计算有多少种合法选择。只考虑所选三个站点的集合，不区分选择顺序。

#### 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行两个整数 $x_i,y_i$，表示观测站的坐标。

#### 输出格式

输出一个整数，表示合法选择的数量。不需要取模。

#### 数据范围

- $3\le n\le2\times10^5$。
- $-10^9\le x_i,y_i\le10^9$，且 $(x_i,y_i)\ne(0,0)$。

本题训练资源约定：时间限制 $3$ 秒，内存限制 $256$ MiB。

2

```

```

#### 样例解释 1

第一条记录要求 $x\le2$，第二条记录要求 $y\le2$。结合矩形边界，可行区域为 $[0,2]\times[0,2]$，面积为 $4$。

### P. 第 $k$ 小的城市距离

**预计难度：CF 2300**

**题目来源：原创训练设计 / 曼哈顿点对距离的顺序统计**

#### 题目描述

平面上有 $n$ 座城市，第 $i$ 座城市的坐标为 $(x_i,y_i)$。城市之间使用曼哈顿距离：

$$
d(i,j)=|x_i-x_j|+|y_i-y_j|.
$$

对所有满足 $1\le i<j\le n$ 的城市对，分别计算距离，得到长度为 $n(n-1)/2$ 的序列。将这个序列按非降序排列，请输出第 $k$ 个数，序号从 $1$ 开始。

不同城市可以位于相同坐标，此时它们之间的距离为 $0$。每一对不同编号的城市都对应序列中的一个元素；不同城市对的距离即使相等，也保留所有重复值。

#### 输入格式

第一行两个整数 $n,k$。

接下来 $n$ 行，每行两个整数 $x_i,y_i$，依次表示各座城市的坐标。

#### 输出格式

输出一个整数，表示第 $k$ 小的城市对距离。

#### 数据范围

$2\le n\le10^5$，$1\le k\le n(n-1)/2$。

所有坐标均为整数，且 $-10^9\le x_i,y_i\le10^9$。允许不同城市的位置重合。

本题训练资源约定：时间限制 $8$ 秒，内存限制 $256$ MiB。

#### 输入样例 1

```text
4 4
0 0
1 0
0 2
3 0
```

#### 输出样例 1

```text
3
```

#### 样例解释 1

六个城市对的距离按非降序排列为 $1,2,2,3,3,5$，第四个数为 $3$。

#### 输入样例 2

```text
3 1
0 0
0 0
1 0
```

#### 输出样例 2

```text
0
```

#### 样例解释 2

前两座城市编号不同，但位于相同位置，所以它们贡献一个距离为 $0$ 的城市对。三个距离依次为 $0,1,1$，最小值为 $0$。
