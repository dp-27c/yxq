# 题目 11：整批缩减

**预估 CF Rating：2300（主观估计，非官方评级）**

模型参考：[Codeforces 850C — Arpa and a game with Mojtaba](https://codeforces.com/problemset/problem/850/C)。本题采用独立编写的中文表述和样例，并调整了数组长度及数值范围。

## 题目描述

黑板上写着 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。两名玩家从给定数组开始游戏，先手先行动，随后双方轮流操作。

一次操作需要选择一个素数 $p$ 和一个正整数 $k$，并且当前至少有一个数能够被 $p^k$ 整除。

确定 $p,k$ 后，对黑板上的全部位置同时进行如下修改：

- 如果该位置上的数能够被 $p^k$ 整除，就将它除以 $p^k$。
- 否则，该位置上的数保持不变。

哪些位置需要改变，只依据本次操作前的数组判断；每个需要改变的位置在这次操作中恰好除以 $p^k$ 一次。不能只处理一部分满足整除条件的位置。

轮到某名玩家时，如果不存在合法的 $p,k$，该玩家失败。双方都采用最优策略。

请判断最终获胜的是先手还是后手。

## 输入格式

第一行包含一个整数 $n$。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

如果先手能够获胜，输出 `First`；否则输出 `Second`。

## 数据范围与约定

- $1\le n\le2\times10^5$。
- $1\le a_i\le10^6$。
- $p$ 必须是素数，$k$ 必须是正整数。
- 数组中的数允许重复，重复值所在的位置仍然同时按照相同规则处理。
- 数组长度始终不变，值变成 $1$ 的位置也保留在数组中。
- 所有除法都要求整除，不进行向下取整。
- 每次合法操作至少使一个正整数严格减小，且不会使任何数变大，因此游戏一定结束。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
4
4 8 3 1
```

**输出：**

```text
First
```

## 样例 1 解释

先手可以选择 $p=2,k=2$，将数组变为 $(1,2,3,1)$。

此时后手只能选择 $p=2,k=1$ 或 $p=3,k=1$。先手随后选择另一种操作，就会使数组变为 $(1,1,1,1)$，后手无法继续。因此先手存在获胜策略。

## 样例 2

**输入：**

```text
3
2 3 6
```

**输出：**

```text
Second
```

## 样例 2 解释

先手只有两种合法选择。

若选择 $p=2,k=1$，数组变为 $(1,3,3)$，后手选择 $p=3,k=1$ 即可结束游戏；若先手选择 $p=3,k=1$，数组变为 $(2,1,2)$，后手选择 $p=2,k=1$ 即可结束游戏。因此后手必胜。
