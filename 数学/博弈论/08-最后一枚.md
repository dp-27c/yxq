# 题目 8：最后一枚

**预估 CF Rating：2200（主观估计，非官方评级）**

## 题目描述

桌上有 $n$ 堆筹码，第 $i$ 堆最初有 $a_i$ 枚。两名玩家轮流操作，先手先操作，双方都采用最优策略。

一次操作选择一堆非空筹码，从这一堆中取走 $t$ 枚，必须满足 $1\le t\le k$，并且不能超过该堆当前的筹码数量。一次操作不能同时影响多堆。

本题采用特殊胜负规则：**取走桌上最后一枚筹码的玩家立即失败。** 因而，若轮到某名玩家时所有筹码堆都为空，则该玩家获胜。特别地，若初始状态就全部为空，先手直接获胜，无需操作。

一个合法的首次操作称为制胜首步，当且仅当先手执行该操作后，能够保证自己最终获胜。

请计算不同的制胜首步共有多少种。两种操作不同，当且仅当选择的筹码堆编号不同，或者取走的筹码数量不同。

## 输入格式

第一行包含一个整数 $T$，表示测试数据组数。

每组数据的第一行包含两个整数 $n,k$。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

对每组数据，输出一行整数，表示制胜首步的数量。

## 数据范围与约束

- $1\le T\le10^4$。
- $1\le n\le2\times10^5$，所有测试数据的 $n$ 之和不超过 $2\times10^5$。
- $1\le k\le10^9$。
- $0\le a_i\le10^{18}$。
- 不同筹码堆按编号区分，允许初始为空，也允许数量相同。
- 一次操作取走的数量上限始终为输入中的 $k$，不会随操作改变。
- 每次操作都使筹码总数严格减少，因此游戏一定会结束。
- 初始全部为空时，虽然先手直接获胜，但不存在合法的首次操作，答案仍为 $0$。
- 答案表示实际操作数量，不取模。

## 样例 1

**输入：**

```text
2
2 2
2 3
2 2
2 2
```

**输出：**

```text
2
0
```

## 样例 1 解释

第一组数据的两种制胜首步分别是从第一堆取走一枚，或者从第二堆取走一枚。操作后分别留下 $(1,3)$ 或 $(2,2)$，先手均能在之后的对局中保证获胜。

第二组数据中，如果先手取走一枚，后手就取空另一堆；如果先手取空一堆，后手就从剩余一堆取走一枚。两种情况下都会给先手留下唯一的一枚筹码，迫使先手取走最后一枚并失败。因此没有制胜首步。

## 样例 2

**输入：**

```text
3
2 3
0 0
1 5
1
2 2
1 1
```

**输出：**

```text
0
0
2
```

## 样例 2 解释

第一组数据中，先手直接获胜，但没有可以计数的首次操作。

第二组数据中，唯一合法操作会取走桌上最后一枚筹码，使先手立即失败。

第三组数据中，先手可以任选一堆并取走其中的一枚。后手随后只能取走最后一枚，因此这两种首次操作都能保证先手获胜。
