# 题目 3：分档提取

**预估 CF Rating：1900（主观估计，非官方评级）**

模型参考：[Codeforces 1194D](https://codeforces.com/problemset/problem/1194/D)。本题采用多个独立仓格，并要求统计必胜首步；数据范围、题面与样例另行编写。

## 题目描述

有 $n$ 个仓格，第 $i$ 个仓格最初放有 $a_i$ 枚筹码。游戏还给定一个正整数 $k$。

两名玩家轮流操作，先手先行动。每次操作选择一个仓格，并从中取走恰好 $1$ 枚、$2$ 枚或 $k$ 枚筹码，前提是该仓格中有足够的筹码。取走的筹码不再放回，其他仓格不变。

轮到某名玩家时，如果所有仓格都无法执行合法操作，该玩家失败。两名玩家都采用最优策略。

请统计先手有多少种必胜的第一次操作。这里，某次操作称为必胜首步，是指先手执行该操作后，能够在后续游戏中保证自己最终获胜，无论后手如何应对。

两次操作不同，当且仅当选择的仓格编号不同，或者实际取走的筹码数量不同。若 $k=1$ 或 $k=2$，相同的实际操作不能因为符合多个提取额度而重复计数。

## 输入格式

第一行包含一个整数 $T$，表示测试数据组数。

每组数据的第一行包含两个整数 $n,k$。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

对每组数据输出一行，包含一个整数，表示必胜首步的数量。

如果先手没有合法操作，或者不存在必胜首步，输出 $0$。

## 数据范围与约束

- $1\le T\le10^4$。
- $1\le n\le2\times10^5$，所有测试数据的 $n$ 之和不超过 $2\times10^5$。
- $1\le k\le10^{18}$，$0\le a_i\le10^{18}$。
- 仓格允许最初为空，多个仓格也可以拥有相同数量的筹码，但不同仓格始终按编号区分。
- 每次操作只能从一个仓格中取走筹码，不能把多个仓格的筹码合并后提取。
- 每次操作都会严格减少筹码总数，因此游戏一定在有限次操作后结束。
- 答案不取模。输入中的较大整数需要使用 $64$ 位整数表示。

## 样例 1

**输入：**

```text
2
3 3
3 4 5
2 4
3 6
```

**输出：**

```text
3
0
```

## 样例 1 解释

第一组数据中，三种必胜首步分别是从第 $1$、第 $2$ 或第 $3$ 个仓格中取走 $2$ 枚筹码。选择的仓格不同，因此它们是三种不同的操作。其他合法首步都无法在后手最优应对时保证获胜。

第二组数据中，先手虽然有合法操作，但不存在能够保证最终获胜的首步。

## 样例 2

**输入：**

```text
3
1 1
1
2 2
1 1
3 6
0 0 0
```

**输出：**

```text
1
0
0
```

## 样例 2 解释

第一组数据中，取走唯一的筹码后，后手无法操作。虽然此时 $k=1$，这个实际操作仍然只计一次。

第二组数据中，先手只能清空一个仓格，后手随后清空另一个仓格，先手将无法继续操作，因此没有必胜首步。

第三组数据的所有仓格最初就为空，先手没有合法操作。
