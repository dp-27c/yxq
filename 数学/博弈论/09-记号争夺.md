# 题目 9：记号争夺

**预估 CF Rating：2200（主观估计，非官方评级）**

模型参考：[UVa 10561](https://onlinejudge.org/external/105/10561.pdf)。本题采用独立编写的中文规格与样例，扩大棋盘长度，并将输出改为必胜首步的数量。

## 题目描述

有一块排成一行的棋盘，当前状态由长度为 $n$ 的字符串 $s$ 表示。字符 `.` 表示空格，字符 `X` 表示该格已经写有记号。输入保证当前棋盘中没有连续三个 `X`。

两名玩家轮流操作，先手先行动。每次操作必须选择一个空格，将其中的 `.` 改为 `X`。

如果本次操作后，棋盘上出现了连续三个 `X`，执行本次操作的玩家立即获胜，游戏随即结束。连续三个 `X` 可以包含预先写好的记号或由任意玩家写下的记号，不要求它们来自同一名玩家。

两名玩家都采用最优策略。请统计先手有多少种必胜的第一次操作，即先手选择该空格写入 `X` 后，能够保证自己最终获胜，无论后手如何应对。若第一次操作就形成了连续三个 `X`，也算作必胜首步。

每个可选择的空格计为一种操作。即使一次落子同时形成多处连续三个 `X`，也只计为一种操作。

## 输入格式

第一行包含一个整数 $T$，表示测试数据组数。

接下来 $T$ 行，每行包含一个字符串 $s$，表示一组数据的初始棋盘。

## 输出格式

对每组数据输出一行，包含一个整数，表示必胜首步的数量。若不存在必胜首步，输出 $0$。

## 数据范围与约束

- $1\le T\le500$。
- 每个字符串的长度满足 $3\le n\le2000$，所有测试数据的字符串长度之和不超过 $2000$。
- 字符串仅由 `.` 和 `X` 组成，且初始时不包含连续三个 `X`。
- 格子编号从左到右为 $1,2,\ldots,n$。
- 只能在空格中写入记号，已经写下的记号不能移动或删除。
- 玩家不能跳过自己的回合。
- 胜负由首次形成连续三个 `X` 的操作决定，不按谁先写满棋盘判定。
- 每次操作都会减少空格数量；棋盘长度至少为 $3$，因此游戏一定在有限次操作内决出胜负，不会出现平局。
- 答案为实际操作数量，不取模。

## 样例 1

**输入：**

```text
2
....
X..X
```

**输出：**

```text
2
0
```

## 样例 1 解释

第一组数据中，必胜首步是在第 $2$ 格或第 $3$ 格写入 `X`。例如，先手在第 $2$ 格写入后，无论后手选择哪个空格，先手都能在下一次操作中形成连续三个 `X`。在两端落子则无法保证获胜。

第二组数据中，先手只能选择第 $2$ 格或第 $3$ 格。无论选择哪一个，后手都可以在剩下的空格写入 `X` 并立即获胜。

## 样例 2

**输入：**

```text
3
XX.XX
...
X.X..
```

**输出：**

```text
1
3
1
```

## 样例 2 解释

第一组数据只有第 $3$ 格为空。先手在该格落子后立即获胜；虽然这次操作形成了多处连续三个 `X`，仍然只是一种首步。

第二组数据中，先手可以选择任意一个空格。后手填入第二个记号后，先手填入最后一个记号便会形成连续三个 `X`，所以三种首步都能获胜。

第三组数据中，先手在第 $2$ 格落子可以立即获胜。若选择其他空格，后手就能在第 $2$ 格落子并获胜，因此只有一种必胜首步。
