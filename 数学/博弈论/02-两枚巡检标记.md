# 题目 2：两枚巡检标记

**预估 CF Rating：1800（主观估计，非官方评级）**

## 题目描述

有 $n$ 个站点和 $m$ 条单向通道，站点编号为 $1,2,\ldots,n$。这些通道构成的有向图中不存在有向环。

对于任意两个不同的站点 $u,v$，可以分别在它们上面放置一枚巡检标记，并开始一场游戏。

两名玩家轮流操作，先手先开始。每次操作选择一枚标记，沿着从它当前所在站点出发的一条单向通道，将这枚标记移动到通道的另一端。

两枚标记互不阻挡，可以位于同一个站点，也可以先后经过相同的站点或通道。移动不会删除站点或通道。若某枚标记所在的站点没有出发通道，则不能选择这枚标记进行操作，但仍可以操作另一枚能够移动的标记。

轮到某名玩家时，如果两枚标记都无法移动，该玩家失败。双方均采用最优策略。

请统计有多少个无序站点对 $\{u,v\}$，满足 $u\ne v$，且以这两个站点作为标记的初始位置时，先手能够保证获胜。

## 输入格式

第一行包含两个整数 $n,m$。

接下来 $m$ 行，每行包含两个整数 $u_i,v_i$，表示一条从站点 $u_i$ 指向站点 $v_i$ 的单向通道。

## 输出格式

输出一个整数，表示使先手能够保证获胜的无序站点对数量。

## 数据范围与约束

- $1\le n\le2\times10^5$，$0\le m\le2\times10^5$。
- $1\le u_i,v_i\le n$，$u_i\ne v_i$。
- 不存在重复的有向通道，输入保证整个有向图不存在有向环。
- 不要求所有站点相互连通，也不要求通道从编号较小的站点指向编号较大的站点。
- 初始位置必须是两个不同站点，但游戏过程中允许两枚标记重合。
- $\{u,v\}$ 与 $\{v,u\}$ 视为同一个站点对，只计一次。
- 每个站点对对应一场独立游戏，不会受到其他站点对的选择或对局影响。
- 答案不取模，可能超过 $32$ 位有符号整数范围。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
4 4
1 2
1 3
2 3
4 3
```

**输出：**

```text
5
```

## 样例 1 解释

共有六个无序站点对，其中只有 $\{2,4\}$ 对应的游戏由后手获胜。从站点 $2,4$ 出发的标记都只能移动到站点 $3$，所以这场游戏恰好进行两次操作，之后轮到先手且两枚标记都无法移动。

其余五个站点对都由先手获胜。例如，对于 $\{1,3\}$，先手将位于站点 $1$ 的标记直接移到站点 $3$，后手便无法操作。两枚标记位于同一站点符合游戏规则。

## 样例 2

**输入：**

```text
5 0
```

**输出：**

```text
0
```

## 样例 2 解释

图中没有通道。无论选择哪两个不同的初始站点，先手一开始都无法操作，因此没有使先手获胜的站点对。
