# 题目 5：双罐清点

**预估 CF Rating：2000（主观估计，非官方评级）**

模型参考：[UVa 10368](https://onlinejudge.org/external/103/10368.pdf)。本题将单组规则扩展为多个独立区域，采用所有区域都无法操作时才结束的统一终局规则，题面与样例另行编写。

## 题目描述

桌面上有 $n$ 个区域，每个区域里放着两个罐子。第 $i$ 个区域的两个罐子最初分别装有 $a_i,b_i$ 枚筹码。

两名玩家轮流操作，先手先行动。每次操作必须选择一个两个罐子都非空的区域，并进行以下操作：

1. 选择其中一个筹码数量不少于另一个的罐子。设选中罐子的筹码数量为 $x$，另一个罐子的筹码数量为 $y$，此时 $x\ge y>0$。
2. 选择一个正整数 $t$，满足 $ty\le x$，从选中的罐子中取走恰好 $ty$ 枚筹码。

另一个罐子的筹码数量保持不变，取走的筹码不再放回。若两个罐子的筹码数量相等，允许选择其中任意一个执行上述操作。

如果某个区域中至少有一个罐子为空，该区域以后不能再被选择，但其他区域仍然可以继续操作。清空一个罐子并不会直接决定整局游戏的胜负。

轮到某名玩家时，如果没有任何区域可以执行合法操作，该玩家失败。两名玩家都采用最优策略，请判断谁会获胜。

## 输入格式

第一行包含一个整数 $T$，表示测试数据组数。

每组数据的第一行包含一个整数 $n$。

接下来 $n$ 行，第 $i$ 行包含两个整数 $a_i,b_i$，表示第 $i$ 个区域中两个罐子的初始筹码数量。

## 输出格式

对每组数据输出一行：如果先手获胜，输出 `First`；否则输出 `Second`。

## 数据范围与约束

- $1\le T\le10^4$。
- $1\le n\le2\times10^5$，所有测试数据的 $n$ 之和不超过 $2\times10^5$。
- $0\le a_i,b_i\le10^{18}$。
- 罐子可以最初就为空；初始时已经无法操作的区域不会影响其他区域的合法操作。
- 一次操作只能改变一个区域中的一个罐子，不能在不同区域之间移动筹码。
- 玩家不能跳过自己的回合；有合法操作时必须选择一次执行。
- 每次操作都会严格减少筹码总数，因此游戏一定在有限次操作后结束。
- 筹码数量使用普通整数表示，不取模。

## 样例 1

**输入：**

```text
2
1
2 5
2
1 2
1 2
```

**输出：**

```text
First
Second
```

## 样例 1 解释

第一组数据中，先手可以从有 $5$ 枚筹码的罐子中取走 $2$ 枚，留下 $(2,3)$。后手此时只能把 $3$ 减为 $1$。先手随后从有 $2$ 枚筹码的罐子中取走 $2$ 枚，使该区域无法继续操作，从而获胜。

第二组数据中，两个区域的初始状态完全相同。先手在一个区域执行操作后，后手可以在另一个区域执行同样的操作。这样，先手每次行动前两个区域都处于相同状态，最终由后手完成最后一次操作。

## 样例 2

**输入：**

```text
3
2
0 7
5 0
1
4 4
2
0 1
2 3
```

**输出：**

```text
Second
First
Second
```

## 样例 2 解释

第一组数据的两个区域都含有空罐，先手没有合法操作。

第二组数据中，先手可以选择任意一个罐子，取走其中全部 $4$ 枚筹码，随后后手无法操作。

第三组数据的第一个区域无法操作。先手只能在第二个区域中将 $3$ 减为 $1$，后手再从有 $2$ 枚筹码的罐子中取走全部筹码，即可获胜。
