# 题目 7：双罐取物

**预估 CF Rating：2100（主观估计，非官方评级）**

## 题目描述

桌上有两个带编号的罐子。第一个罐子装有 $a$ 枚筹码，第二个罐子装有 $b$ 枚筹码。

两名玩家轮流操作，先手先操作。每次操作必须选择以下两种方式之一：

- 选择一个罐子，从中取走任意正整数枚筹码。
- 从两个罐子中分别取走相同的正整数枚筹码。

任何操作都不能取走超过相应罐子现有数量的筹码。轮到某名玩家时，如果没有合法操作，该玩家失败。

双方都采用最优策略。一个合法的首次操作称为制胜首步，当且仅当先手执行它之后，仍然能够保证最终获胜。

请计算有多少种不同的制胜首步。两种操作不同，当且仅当它们从第一个罐子取走的数量不同，或者从第二个罐子取走的数量不同。

## 输入格式

第一行包含一个整数 $T$，表示测试数据组数。

接下来 $T$ 行，每行包含两个整数 $a,b$，描述一局游戏的初始状态。

## 输出格式

对每组数据，输出一行整数，表示制胜首步的数量。

## 数据范围与约束

- $1\le T\le2\times10^5$。
- $0\le a,b\le10^{18}$。
- 两个罐子按编号区分，即使其中的筹码数量相同也不视为同一个罐子。
- 一次操作可以清空一个罐子，也可以同时清空两个罐子。
- 每次操作都使筹码总数严格减少，因此游戏一定会结束。
- 若先手无法保证获胜，制胜首步数量为 $0$。
- 若两个罐子初始都为空，先手立即失败，答案为 $0$。
- 答案表示实际操作数量，不取模。

## 样例 1

**输入：**

```text
2
2 2
1 2
```

**输出：**

```text
3
0
```

## 样例 1 解释

第一组数据有三种制胜首步：只从第一个罐子取走一枚、只从第二个罐子取走一枚，或者从两个罐子各取走两枚。前两种操作分别留下 $(1,2)$ 和 $(2,1)$，第三种操作直接让后手没有合法操作。

第二组数据中，先手的所有合法操作分别会留下 $(0,2)$、$(1,1)$、$(1,0)$ 或 $(0,1)$。在每一种情况下，后手都能用一次合法操作清空剩余筹码并获胜。因此没有制胜首步。

## 样例 2

**输入：**

```text
3
0 0
0 1000000000000000000
1 1
```

**输出：**

```text
0
1
1
```

## 样例 2 解释

第一组数据没有合法操作。

第二组数据中，唯一的制胜首步是一次取走第二个罐子中的全部筹码；如果留下任何筹码，后手都能一次取完。

第三组数据中，只有同时取走两个罐子中的筹码才能获胜。
