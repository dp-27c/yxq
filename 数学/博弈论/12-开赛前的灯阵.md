# 题目 12：开赛前的灯阵

**预估 CF Rating：2400（主观估计，非官方评级）**

## 题目描述

一排灯的位置编号为 $1,2,\ldots,M$，每盏灯只有亮、灭两种状态。最初，只有给定的 $n$ 个不同位置 $a_1,a_2,\ldots,a_n$ 可能亮着，其他位置的灯全部熄灭。

用一个长度为 $n$ 的二进制字符串 $b$ 描述这些指定位置的初始状态：$b_i=1$ 表示位置 $a_i$ 的灯亮着，$b_i=0$ 表示它熄灭。

开赛前，工作人员可以使用 $m$ 个联动开关。第 $j$ 个开关连接两个不同的指定位置 $a_{u_j},a_{v_j}$。按下这个开关，会同时翻转这两盏灯的状态，即亮变灭、灭变亮。

工作人员可以任选一些开关，各按一次，也可以一个都不按。所有开关按完后得到的灯阵，将作为一局游戏的初始状态。开关准备过程不属于两名玩家的游戏过程。

两名玩家从这个灯阵开始游戏，先手先行动，随后双方轮流操作。一次操作必须完成以下动作：

1. 选择一盏当前亮着的灯，设其位置为 $x$，将它熄灭。
2. 可以再选择一个满足 $1\le y<x$ 的位置，将位置 $y$ 的灯翻转一次；也可以不执行这一步。

第二步选择的灯可以原本亮着，也可以原本熄灭。它不必属于输入中列出的 $n$ 个指定位置。游戏开始后，任何位置的亮灯都可以作为第一步的选择对象，联动开关则不再使用。

轮到某名玩家时，如果没有亮着的灯，该玩家失败。双方都采用最优策略。

请统计工作人员能够准备出的不同灯阵中，有多少个灯阵会使后手获胜，答案对 $10^9+7$ 取模。

两个灯阵不同，当且仅当至少一个位置的亮灭状态不同。同一个灯阵即使可以通过不同的开关选择得到，也只能计数一次。

## 输入格式

第一行包含三个整数 $M,n,m$。

第二行包含 $n$ 个两两不同的整数 $a_1,a_2,\ldots,a_n$。

第三行包含一个长度为 $n$、仅由字符 `0` 和 `1` 组成的字符串 $b$。

接下来 $m$ 行，第 $j$ 行包含两个整数 $u_j,v_j$，描述第 $j$ 个开关。这里的下标指向输入数组 $a$，不是灯的位置编号。

## 输出格式

输出一个整数，表示能使后手获胜的不同初始灯阵数量对 $10^9+7$ 取模后的结果。

## 数据范围与约定

- $1\le M\le10^{18}$。
- $1\le n\le\min(M,2\times10^5)$，$0\le m\le2\times10^5$。
- $1\le a_i\le M$，所有 $a_i$ 两两不同，但不保证按位置递增给出。
- 每个开关满足 $1\le u_j,v_j\le n$ 且 $u_j\ne v_j$。
- 允许多个不同开关连接同一对指定位置；这些开关各自至多按一次。
- 工作人员不受两名玩家操作规则的限制，只按照开关规则准备初态。
- 每个可准备出的灯阵都对应一局独立游戏。游戏过程中不能再按联动开关。
- 翻转不会改变灯的位置，也不会改变 $M$。
- 每次操作后，所有亮灯的位置编号之和都会严格减小，因此游戏一定在有限次操作后结束。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
5 5 5
1 2 3 4 5
00000
1 2
2 3
3 4
4 5
5 1
```

**输出：**

```text
2
```

## 样例 1 解释

恰有两种可准备出的灯阵使后手获胜：全部灯熄灭，以及恰好位置 $2,3,4,5$ 的灯亮着。

前一种可以通过不按任何开关得到，先手一开始就无法操作。后一种可以通过按下第 $2,4$ 个开关得到；从该灯阵开始，双方最优行动时后手获胜。

同一灯阵可能对应多种开关选择。例如，不按开关与按下全部五个开关都会得到全部灯熄灭的状态，但它只计数一次。

## 样例 2

**输入：**

```text
1 1 0
1
1
```

**输出：**

```text
0
```

## 样例 2 解释

没有联动开关，工作人员只能保留唯一一盏灯亮着的初态。先手将它熄灭后，后手无法操作，因此没有能使后手获胜的初始灯阵。
