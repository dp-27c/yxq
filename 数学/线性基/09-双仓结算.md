# 题目 9：双仓结算

## 题目描述

两个仓库分别保存了 $n$ 枚和 $m$ 枚结算筹码。第一仓库第 $i$ 枚筹码的编号值为 $a_i$，第二仓库第 $j$ 枚筹码的编号值为 $b_j$。

你可以从每个仓库中分别选择若干枚筹码，每枚至多选择一次。设第一仓库所选编号值的按位异或为 $u$，第二仓库所选编号值的按位异或为 $v$。

本次结算给定一个整数 $d$，要求

$$
u\oplus v=d.
$$

在满足要求的所有选法中，求普通整数加法所得的 $u+v$ 的最大值。若不存在满足要求的选法，输出 $-1$。

## 输入格式

第一行包含三个整数 $n,m,d$。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$。

第三行包含 $m$ 个整数 $b_1,b_2,\ldots,b_m$。

## 输出格式

输出最大结算值 $u+v$；无解时输出 $-1$。

## 数据范围与约定

- $n,m\ge1$，$n+m\le2\times10^5$。
- $0\le a_i,b_j,d<2^{60}$。
- $\oplus$ 表示按位异或；目标中的加号表示普通整数加法。
- 每个仓库都允许选择空集合，空集合的异或值为 $0$。
- 编号值可以为 $0$ 或重复，但每枚筹码至多选择一次。
- 答案不取模，可能超过 $32$ 位有符号整数范围。
- 输入仅包含一组数据，所有整数使用十进制表示。

## 样例 1

**输入：**

```text
3 3 4
3 5 6
1 2 7
```

**输出：**

```text
10
```

## 样例 1 解释

第一仓库选择第 $1$ 枚筹码，第二仓库选择第 $3$ 枚筹码，得到 $u=3,v=7$。

此时 $3\oplus7=4$，结算值为 $3+7=10$。没有合法选法能得到更大的结算值。

## 样例 2

**输入：**

```text
3 3 1
0 2 2
0 4 4
```

**输出：**

```text
-1
```

## 样例 2 解释

第一仓库只能得到 $0$ 或 $2$，第二仓库只能得到 $0$ 或 $4$。

两者的异或只能为 $0,2,4,6$，无法满足给定的 $d=1$。
