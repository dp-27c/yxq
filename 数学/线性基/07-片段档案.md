# 题目 7：片段档案

## 题目描述

有一列长度为 $n$ 的记录，第 $i$ 条记录的值为非负整数 $a_i$。

一份档案由三个整数 $(l,r,x)$ 唯一确定，满足 $1\le l\le r\le n$ 且 $x>0$。如果可以从第 $l$ 条到第 $r$ 条记录中选择若干个不同下标，使所选值的按位异或等于 $x$，则这份档案有效。

即使有多种选择得到相同的 $x$，同一个 $(l,r,x)$ 仍然只算一份档案。

请计算有效档案的总数，对 $10^9+7$ 取模。

## 输入格式

第一行包含一个整数 $n$。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

输出一个整数，表示有效档案总数对 $10^9+7$ 取模后的结果。

## 数据范围与约定

- $1\le n\le10^5$。
- $0\le a_i<2^{60}$，记录值允许重复。
- 每个下标至多选择一次，被选择的下标可以不连续。
- 空选择的异或值定义为 $0$。
- 档案要求 $x>0$，因此异或结果为 $0$ 的任何选择均不产生有效档案。
- $(l,r)$ 不同的档案分别计数，即使它们的 $x$ 相同。
- 输入仅包含一组数据，所有整数使用十进制表示。

## 样例 1

**输入：**

```text
3
1 2 3
```

**输出：**

```text
12
```

## 样例 1 解释

三个长度为 $1$ 的区间各产生一份档案。

两个长度为 $2$ 的区间各能得到非零结果 $1,2,3$，各产生三份档案。整个区间也只产生三份档案。

因此总数为 $3+6+3=12$。

## 样例 2

**输入：**

```text
4
0 5 5 0
```

**输出：**

```text
8
```

## 样例 2 解释

共有八个区间包含至少一个值为 $5$ 的记录，每个这样的区间恰好产生一份 $x=5$ 的档案。

其余两个区间分别为 $[1,1]$ 和 $[4,4]$，不能产生有效档案。
