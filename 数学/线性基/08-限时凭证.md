# 题目 8：限时凭证

## 题目描述

系统中最初没有凭证。每张凭证都有一个唯一编号和一个非负整数值。你需要按顺序执行以下操作：

- `+ id x`：加入编号为 $id$、值为 $x$ 的凭证。
- `- id`：移除编号为 $id$ 的凭证。
- `? x`：从当前仍在系统中的凭证里选择至少一张，求所选凭证值的按位异或等于 $x$ 的选择方案数，对 $10^9+7$ 取模。

选择方案按凭证编号集合区分。不同凭证即使值相等，也视为不同对象。

询问不会移除凭证，也不会影响之后的操作。

## 输入格式

第一行包含一个整数 $q$，表示操作数。

接下来 $q$ 行，每行按题目描述中的格式给出一个操作。

## 输出格式

对每个 `?` 操作，输出一行，表示对应的方案数对 $10^9+7$ 取模后的结果。

## 数据范围与约定

- $1\le q\le10^5$，至少有一个询问操作。
- 所有加入或询问的值满足 $0\le x<2^{30}$。
- 所有编号满足 $1\le id\le q$。
- 每次加入使用的编号此前从未出现于加入操作中；移除后的编号也不再复用。
- 每次移除的凭证保证当前存在。
- 每张凭证在一次选择中至多使用一次，不能选择空集合。
- 当前没有凭证时，所有询问的答案均为 $0$。
- 输入仅包含一组数据，所有整数使用十进制表示。

## 样例 1

**输入：**

```text
11
+ 1 1
+ 2 2
? 3
+ 3 3
? 3
- 2
? 3
? 0
+ 4 0
? 0
? 1
```

**输出：**

```text
1
2
1
0
1
2
```

## 样例 1 解释

第一次询问中，得到 $3$ 的编号集合只有 $\{1,2\}$。第二次询问中，可以选择 $\{1,2\}$ 或 $\{3\}$。

移除编号 $2$ 后，得到 $3$ 的方案只有 $\{3\}$，没有非空方案能得到 $0$。

加入编号 $4$ 后，得到 $0$ 的方案为 $\{4\}$；得到 $1$ 的方案为 $\{1\}$ 和 $\{1,4\}$。

## 样例 2

**输入：**

```text
9
? 0
+ 1 0
+ 2 0
? 0
- 1
? 0
- 2
? 0
? 7
```

**输出：**

```text
0
3
1
0
0
```

## 样例 2 解释

两张值为 $0$ 的凭证同时存在时，三个非空编号集合 $\{1\}$、$\{2\}$、$\{1,2\}$ 都得到 $0$。

只剩一张时有一种方案。系统为空时，即使目标为 $0$，也不能使用空选择。
