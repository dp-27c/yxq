# 题目 3：同码配对

## 题目描述

有两批带编号的记录。第一批包含 $n$ 条，第 $i$ 条记录的校验值为 $a_i$；第二批包含 $m$ 条，第 $j$ 条记录的校验值为 $b_j$。

你需要从第一批中选择一个非空下标集合 $S$，从第二批中选择一个非空下标集合 $T$，并要求

$$
\bigoplus_{i\in S}a_i=\bigoplus_{j\in T}b_j,
$$

其中 $\oplus$ 表示按位异或。

请计算满足条件的选法对 $(S,T)$ 的数量，对 $10^9+7$ 取模。

## 输入格式

第一行包含两个整数 $n,m$。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$。

第三行包含 $m$ 个整数 $b_1,b_2,\ldots,b_m$。

## 输出格式

输出满足条件的选法对数量对 $10^9+7$ 取模后的结果。

## 数据范围与约定

- $n,m\ge1$，$n+m\le2\times10^5$。
- $0\le a_i,b_j<2^{60}$。
- 两个集合都必须非空，但它们共同得到的异或值允许为 $0$。
- 每条记录至多被选一次。同一批中相同校验值的记录仍按不同编号区分。
- 两个选法对不同，当且仅当它们的 $S$ 不同或 $T$ 不同；不按共同校验值去重。
- 输入仅包含一组数据，所有整数使用十进制表示。

## 样例 1

**输入：**

```text
3 3
1 2 3
1 1 2
```

**输出：**

```text
13
```

## 样例 1 解释

对于每一批记录，非空选择得到校验值 $0$ 的方式有 $1$ 种，得到 $1,2,3$ 的方式各有 $2$ 种。

因此合法选法对共有

$$
1\times1+2\times2+2\times2+2\times2=13
$$

种。

## 样例 2

**输入：**

```text
2 1
0 0
0
```

**输出：**

```text
3
```

## 样例 2 解释

第一批可以选择 $\{1\}$、$\{2\}$ 或 $\{1,2\}$，第二批必须选择 $\{1\}$。

三种选法对的两侧异或值都为 $0$，因此答案为 $3$。
