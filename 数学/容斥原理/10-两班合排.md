# 题目 10：两班合排

## 题目描述

有 $m$ 项任务，编号为 $1,2,\ldots,m$，以及甲、乙两个班组。每个班组都准备了若干份可选工作方案，一份方案规定了这个班组负责完成的任务集合。

任务集合的编码是其中各项任务对应数值之和，任务 $j$ 对应数值 $2^{j-1}$。空任务集合的编码为 $0$。

对于每个编码 $s=0,1,\ldots,2^m-1$，已知甲班组有 $f_s$ 份任务集合编码为 $s$ 的方案，乙班组有 $g_s$ 份这样的方案。同一班组内的不同方案始终视为不同方案，即使它们安排的任务集合相同。

排班时，每个班组都必须恰好选择一份自己的方案。同一项任务不能同时出现在两份选中的方案中。允许有任务没有安排给任何班组，也允许某个班组选中不安排任何任务的方案。

一次合法排班最终安排的任务集合，是两个班组选中方案的任务集合合并后的结果。

对于每个编码 $s=0,1,\ldots,2^m-1$，请统计最终安排的任务集合编码恰好为 $s$ 的合法排班数量，答案对 $998244353$ 取模。

只要甲班组或乙班组选中的方案不同，就视为不同排班。甲、乙班组有明确区别，不交换两者的身份。

## 输入格式

第一行包含一个整数 $m$。

第二行包含 $2^m$ 个整数，依次为 $f_0,f_1,\ldots,f_{2^m-1}$。

第三行包含 $2^m$ 个整数，依次为 $g_0,g_1,\ldots,g_{2^m-1}$。

## 输出格式

输出一行 $2^m$ 个整数，依次表示最终安排的任务集合编码为 $0,1,\ldots,2^m-1$ 的合法排班数量对 $998244353$ 取模后的结果。

## 数据范围与约定

- $1\le m\le20$。
- $0\le f_s,g_s\le10^9$。
- $f_s,g_s$ 是方案的实际数量，不是已经取模后的数值。
- 若某个班组没有任何方案，则不存在合法排班。
- 每个班组必须选择一份方案；没有选择方案与选择空任务集合的方案是不同的，前者不允许。
- 不同方案可能对应相同任务集合，它们各自参与计数。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
2
1 2 1 0
1 1 0 1
```

**输出：**

```text
1 3 1 2
```

## 样例 1 解释

两个班组各有一份空方案，因此不安排任何任务有一种排班。

只安排任务 $1$ 时，可以由甲选择其两份只安排任务 $1$ 的方案之一、乙选择空方案；也可以由甲选择空方案、乙选择其只安排任务 $1$ 的方案，共三种排班。

只安排任务 $2$ 时，只能由甲负责，乙选择空方案，共一种排班。

安排全部任务有两种排班：甲选择空方案、乙选择安排全部任务的方案；或者甲选择只安排任务 $2$ 的方案、乙选择只安排任务 $1$ 的方案。

## 样例 2

**输入：**

```text
1
0 1
0 1
```

**输出：**

```text
0 0
```

## 样例 2 解释

每个班组都只有一份方案，并且都安排任务 $1$。由于同一任务不能同时交给两个班组，没有合法排班。
