# 题目 1：交接顺序

## 题目描述

有 $n$ 份互不相同的档案，编号为 $1,2,\ldots,n$。它们原先按照排列 $a_1,a_2,\ldots,a_n$ 放在一排。

管理员在其中 $m$ 个相邻位置之间做了标记。第 $j$ 个标记的位置为 $t_j$，表示原先紧邻且依次出现的档案 $a_{t_j},a_{t_j+1}$ 需要解除这种交接关系。

现在要重新排列全部档案。对于每一个被标记的位置 $t_j$，在新排列的任何地方，都不能出现档案 $a_{t_j}$ 后面紧接着档案 $a_{t_j+1}$ 的情况。

这两份档案可以相隔若干份档案，也可以按照相反的顺序相邻。没有被标记的相邻关系不受限制。

请计算合法的新排列数量，答案对 $998244353$ 取模。

## 输入格式

第一行包含一个整数 $T$，表示测试数据组数。

每组数据的第一行包含两个整数 $n,m$。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$，描述原排列。

接下来 $m$ 行，每行包含一个整数 $t_j$，表示一个被标记的位置。

## 输出格式

对每组数据输出一行，包含一个整数，表示合法的新排列数量对 $998244353$ 取模后的结果。

## 数据范围与约定

- $1\le T\le10^4$。
- $1\le n\le2\times10^5$，所有测试数据的 $n$ 之和不超过 $2\times10^5$。
- $0\le m<n$。
- $a_1,a_2,\ldots,a_n$ 是 $1,2,\ldots,n$ 的一个排列。
- $1\le t_j<n$，同一组数据中的所有 $t_j$ 两两不同。
- 所有档案都必须出现，且每份恰好出现一次。
- 档案排成一条直线，最后一份档案与第一份档案不相邻。
- 两种方案不同，当且仅当某个位置上的档案编号不同。调整档案时采用的操作顺序不计入方案。
- $m=0$ 时，该组数据没有标记位置的输入行，也没有相邻关系限制。

## 样例 1

**输入：**

```text
2
4 2
4 1 3 2
1
3
3 2
1 2 3
1
2
```

**输出：**

```text
14
3
```

## 样例 1 解释

第一组数据中，禁止档案 $4$ 后面紧接档案 $1$，也禁止档案 $3$ 后面紧接档案 $2$。以 $1,2,3,4$ 开头的合法排列分别有 $4,4,3,3$ 种，共 $14$ 种。例如，$(1,4,2,3)$ 合法。

第二组数据中，三个合法排列分别为 $(1,3,2)$、$(2,1,3)$ 和 $(3,2,1)$。其中 $(3,2,1)$ 虽然包含两对相邻档案，但它们的顺序都与被禁止的方向相反，因此合法。

## 样例 2

**输入：**

```text
2
1 0
1
3 0
2 3 1
```

**输出：**

```text
1
6
```

## 样例 2 解释

两组数据都没有相邻关系限制。第一组数据只有唯一的一份档案，因此只有一种排列；第二组数据的三个不同档案共有六种排列，全部合法。
