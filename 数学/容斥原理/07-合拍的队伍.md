# 题目 7：合拍的队伍

## 题目描述

有 $n$ 名队员，编号为 $1,2,\ldots,n$。每名队员属于红队或蓝队，并有一个正整数节拍数 $a_i$。

现在要从这些队员中选出一支联合队伍，要求红队和蓝队都至少有一名队员入选。队伍的统一拍长定义为所有入选队员节拍数的最大公约数。

对于每个整数 $d=1,2,\ldots,V$，请统计统一拍长恰好为 $d$ 的联合队伍有多少支。答案对 $998244353$ 取模。

一支队伍由入选队员的编号集合确定。即使两名队员属于同一队且节拍数相同，他们仍是不同的队员；只要入选编号集合不同，就视为不同的队伍。队员在队伍中的排列顺序不计入方案。

## 输入格式

第一行包含两个整数 $n,V$。

接下来 $n$ 行，第 $i$ 行包含一个整数 $a_i$ 和一个字符 $c_i$。字符 `R` 表示第 $i$ 名队员属于红队，字符 `B` 表示其属于蓝队。

## 输出格式

输出一行 $V$ 个整数。第 $d$ 个整数表示统一拍长恰好为 $d$ 的联合队伍数量对 $998244353$ 取模后的结果。

## 数据范围与约定

- $1\le n,V\le2\times10^5$。
- $1\le a_i\le V$。
- $c_i$ 为 `R` 或 `B`。
- 不保证输入中红队和蓝队都有人。
- 每名队员至多入选一次，允许不选择部分队员。
- 联合队伍必须同时包含两个颜色的队员，因此空队伍不合法。
- $V$ 只是节拍数的上界，不要求存在节拍数为 $V$ 的队员。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
4 6
2 R
4 R
3 B
6 B
```

**输出：**

```text
6 3 0 0 0 0
```

## 样例 1 解释

如果蓝队入选的队员只有第 $4$ 名，则红队可以选择编号集合 $\{1\}$、$\{2\}$ 或 $\{1,2\}$。这三支联合队伍的统一拍长都是 $2$。

如果第 $3$ 名队员入选，第 $4$ 名队员可以入选，也可以不入选；再配合三种非空的红队选择，共得到六支统一拍长为 $1$ 的队伍。不存在其他合法队伍。

## 样例 2

**输入：**

```text
3 3
2 R
2 R
2 B
```

**输出：**

```text
0 3 0
```

## 样例 2 解释

三支合法队伍的编号集合分别是 $\{1,3\}$、$\{2,3\}$ 和 $\{1,2,3\}$，统一拍长均为 $2$。

前两支队伍虽然包含相同的节拍数，但选择了不同编号的红队队员，因此分别计数。
