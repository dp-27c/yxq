# 题目 13：并行验收

## 题目描述

实验室有 $n$ 台机器，编号为 $1,2,\ldots,n$，开始时都尚未通过验收。

实验从第 $1$ 天开始进行。每天，每台尚未通过验收的机器都会进行若干次尝试：第 $i$ 台机器每天进行恰好 $a_i$ 次尝试。每次尝试以 $1/2$ 的概率成功，以 $1/2$ 的概率失败，所有机器、所有天数中的全部尝试相互独立。

如果一台机器当天的尝试中至少有一次成功，它便在当天结束时通过验收，以后不再进行尝试；如果全部失败，则它在下一天继续按照相同规则进行尝试。

每天结束时，实验室统计累计通过验收的机器数量。当这一数量第一次达到或超过 $k$ 时，整个实验结束。

请计算实验持续天数的期望。最后一天有多台机器同时通过验收时，它们全部计入当天的累计数量，不需要在这些机器之间确定先后顺序。

## 输入格式

第一行包含两个整数 $n,k$。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

输出一个整数，表示实验持续天数的期望对 $998244353$ 取模的结果。

具体地，若期望写成最简分数 $u/v$，应输出 $u\cdot v^{-1}\bmod 998244353$，其中 $v^{-1}$ 表示 $v$ 在该模数下的乘法逆元。在本题数据范围内，期望有限，且最简分数的分母不被 $998244353$ 整除。

## 数据范围与约定

- $1\le n\le80$，$1\le k\le n$。
- 所有 $a_i$ 都是正整数，且 $\sum_{i=1}^{n}a_i\le6000$。
- 各台机器同时进行每天的尝试，一天无论共进行了多少次尝试，都只计为一天。
- 只有在每天结束时才更新验收结果并判断是否结束，不会在当天的尝试进行到一半时停止实验。
- 一台机器一旦通过验收，就一直保持通过状态。
- 不同机器允许具有相同的 $a_i$，但它们的随机尝试仍然相互独立。
- 初始时没有机器通过验收，实验持续天数至少为 $1$。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
3 2
1 1 2
```

**输出：**

```text
313733941
```

## 样例 1 解释

前两台机器各自在一天内通过验收的概率为 $1/2$，第三台为 $3/4$。

第一天结束时，以 $10/16$ 的概率已经有至少两台机器通过验收；以 $1/16$ 的概率没有机器通过；以 $2/16$ 的概率只有前两台中的一台通过；以 $3/16$ 的概率只有第三台通过。

这些情况对应的后续实验过程给出的总天数期望为 $52/35$，取模后的结果为 $313733941$。如果三台机器在同一天通过，也会立即结束实验，不要求累计数量恰好为 $2$。

## 样例 2

**输入：**

```text
1 1
2
```

**输出：**

```text
332748119
```

## 样例 2 解释

唯一的机器每天进行两次尝试，只有两次都失败时才需要继续到下一天。因此，每天通过验收的概率为 $3/4$，实验持续天数的期望为 $4/3$，对应的输出为 $332748119$。
