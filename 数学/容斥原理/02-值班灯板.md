# 题目 2：值班灯板

## 题目描述

一块灯板有 $n$ 行、$m$ 列，每个位置都安装了一盏灯。每盏灯可以亮着，也可以熄灭。

一个灯板状态需要同时满足以下要求：

- 每一行都至少有一盏亮灯。
- 每一列都至少有一盏亮灯。
- 所有亮灯的总数除以 $2$ 的余数恰好为给定的 $p$。

请计算满足要求的不同灯板状态数量，答案对 $998244353$ 取模。

## 输入格式

输入一行，包含三个整数 $n,m,p$。

## 输出格式

输出一个整数，表示合法灯板状态数量对 $998244353$ 取模后的结果。

## 数据范围与约定

- $1\le n\le2\times10^5$。
- $1\le m\le10^{18}$。
- $p\in\{0,1\}$。
- 行和列都有固定编号，不能通过交换行或交换列将两个状态视为相同。
- 两个灯板状态不同，当且仅当至少一个位置的亮灭状态不同。
- $p=0$ 表示亮灯总数必须为偶数，$p=1$ 表示亮灯总数必须为奇数。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
2 3 0
```

**输出：**

```text
13
```

## 样例 1 解释

每列至少有一盏亮灯，而亮灯总数必须为偶数。因此，合法状态要么恰有一列的两盏灯都亮着，要么三列的两盏灯都亮着。

第一种情况下，可以选择哪一列全部亮着，并为另外两列分别选择其中一盏灯亮着，共有 $12$ 种状态。第二种情况下只有一种状态。这些状态的每一行也都有亮灯，所以答案为 $13$。

## 样例 2

**输入：**

```text
1 4 1
```

**输出：**

```text
0
```

## 样例 2 解释

灯板只有一行。为了让每一列都有亮灯，四盏灯必须全部亮着，此时亮灯总数为偶数，不满足 $p=1$，因此不存在合法状态。
