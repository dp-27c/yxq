# 题目 8：协作模块

## 题目描述

仓库中有 $n$ 个模块，编号为 $1,2,\ldots,n$。共有 $m$ 种功能，编号为 $1,2,\ldots,m$，每个模块可以提供其中若干种功能，也可以不提供任何功能。

一个功能集合的编码定义为其中各功能对应数值之和：功能 $j$ 对应数值 $2^{j-1}$。因此，每个功能集合唯一对应 $0$ 到 $2^m-1$ 之间的一个整数，空功能集合的编码为 $0$。第 $i$ 个模块提供的功能集合编码为 $a_i$。

现在要从仓库中恰好选择 $k$ 个模块组成一套设备。设备具备某种功能，当且仅当至少一个选中模块提供这种功能。不同模块可以提供相同的功能，同一种功能由多个模块提供时，仍只算设备具备这一种功能。

对于每个编码 $s=0,1,\ldots,2^m-1$，请统计设备最终具备的功能集合编码恰好为 $s$ 的选择方案数，答案对 $998244353$ 取模。

选择方案由选中模块的编号集合确定，模块的安装顺序不计入方案。

## 输入格式

第一行包含三个整数 $n,m,k$。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

输出一行 $2^m$ 个整数，依次表示最终功能集合编码为 $0,1,\ldots,2^m-1$ 的方案数对 $998244353$ 取模后的结果。

## 数据范围与约定

- $1\le n\le2\times10^5$，$1\le m\le20$。
- $0\le k\le n$。
- $0\le a_i<2^m$。
- 不同模块允许提供完全相同的功能，但编号不同的模块仍分别计数。
- 每个模块至多选择一次。
- 当 $k=0$ 时，唯一的选择方案是不选择任何模块，此时设备没有功能。
- 即使选中了模块，设备的功能集合也可能为空。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
5 2 2
0 1 2 3 1
```

**输出：**

```text
0 3 1 6
```

## 样例 1 解释

共有十种选择两个模块的方案。

编号集合 $\{1,2\}$、$\{1,5\}$ 和 $\{2,5\}$ 对应的设备只具备功能 $1$，编码为 $1$。编号集合 $\{1,3\}$ 对应的设备只具备功能 $2$，编码为 $2$。

其余六种方案都会让设备同时具备两种功能，编码为 $3$。不存在最终功能集合为空的方案。

## 样例 2

**输入：**

```text
3 2 0
0 1 3
```

**输出：**

```text
1 0 0 0
```

## 样例 2 解释

要求恰好选择零个模块，因此只有空选择这一种方案，最终功能集合的编码为 $0$。
