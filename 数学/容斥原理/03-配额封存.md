# 题目 3：配额封存

## 题目描述

有 $n$ 个带编号的储位，需要把恰好 $S$ 枚相同的筹码全部分配给它们。

第 $i$ 个储位的最低配额为 $l_i$，容量上限为 $u_i$。设最终分配给它的筹码数量为 $x_i$，必须满足

$$
l_i\le x_i\le u_i,\qquad \sum_{i=1}^{n}x_i=S.
$$

封存验收还有两个要求：

- 至少一个储位的筹码数量恰好等于它自己的最低配额。
- 至少一个储位的筹码数量恰好等于它自己的容量上限。

这两个要求可以由不同储位满足，也可以由同一个储位满足。特别地，如果某个储位满足 $l_i=u_i$，那么只要分配符合它的配额限制，这个储位就同时满足上述两个要求。

请计算通过验收的分配方案数量，答案对 $998244353$ 取模。

## 输入格式

第一行包含两个整数 $n,S$。

接下来 $n$ 行，第 $i$ 行包含两个整数 $l_i,u_i$，表示第 $i$ 个储位的最低配额和容量上限。

## 输出格式

输出一个整数，表示通过验收的分配方案数量对 $998244353$ 取模后的结果。若不存在合法方案，输出 $0$。

## 数据范围与约定

- $1\le n\le18$。
- $0\le S\le10^{12}$。
- $0\le l_i\le u_i\le10^{12}$。
- 每个 $x_i$ 必须是非负整数。
- 所有筹码都必须分配，不能剩余，也不能从外部补充筹码。
- 储位按编号区分。两种方案不同，当且仅当至少一个储位分得的筹码数量不同。
- 同一个数量向量即使有多个储位达到下界或上界，也只计为一种方案。
- 筹码彼此相同，放入筹码的先后顺序不计入方案。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
3 6
1 3
0 3
1 4
```

**输出：**

```text
6
```

## 样例 1 解释

通过验收的六个数量向量为

$$
(1,1,4),\ (1,3,2),\ (2,0,4),\ (2,3,1),\ (3,0,3),\ (3,2,1).
$$

例如，$(2,0,4)$ 中第 $2$ 个储位达到最低配额，第 $3$ 个储位达到容量上限。向量 $(2,2,2)$ 虽然满足总量和各储位的范围限制，却没有储位达到自己的最低配额或容量上限，因此不能通过验收。

## 样例 2

**输入：**

```text
3 4
1 1
0 3
0 3
```

**输出：**

```text
4
```

## 样例 2 解释

第 $1$ 个储位必须分得一枚筹码，并同时达到它的最低配额和容量上限。通过验收的四个数量向量为 $(1,0,3)$、$(1,1,2)$、$(1,2,1)$ 和 $(1,3,0)$。
