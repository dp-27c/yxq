# 题目 6：双区记账

## 题目描述

一座展厅分为左区和右区。左区有 $a$ 个展台，右区有 $b$ 个展台，所有展台都可以按所在区域和区内编号区分。

任意一个左区展台和任意一个右区展台之间，都可以设置一条连接线。同一区域内的展台之间不能连线，每对展台之间至多设置一条连接线。

对于每一种非空的连接线选取方案 $S$，进行一次独立记账：

1. 为所有展台分别选择一种颜色，颜色编号为 $1,2,\ldots,c$。
2. 每条被选中的连接线，其两端展台必须具有相同颜色。没有被选中的连接线不施加任何要求。
3. 设满足上述要求的染色方案数为 $F(S)$。如果 $S$ 中连接线的数量为奇数，就给甲的账目增加 $F(S)$；否则给乙的账目增加 $F(S)$。

两个染色方案不同，当且仅当至少一个展台的颜色不同。不与任何已选连接线相接的展台也需要染色，并且可以选择任意颜色。

甲、乙的初始账目均为 $0$。所有非空连接线选取方案都恰好记账一次后，请计算甲的账目减去乙的账目所得结果，对 $10^9+7$ 取模。

## 输入格式

输入一行，包含三个整数 $a,b,c$。

## 输出格式

输出一个整数，表示账目之差对 $10^9+7$ 取模后的结果。输出必须位于 $0$ 到 $10^9+6$ 之间。

## 数据范围与约定

- $0\le a\le2000$，$0\le b\le10^{18}$。
- $1\le c\le10^9$。
- 两个区域中的展台均有编号，交换不同展台的颜色可能产生不同染色方案。
- 颜色编号可区分，不要求每种颜色都被使用。
- 连接线选取方案只由选中的连接线集合决定，不区分选取顺序。
- 空连接线方案不参与记账。若不存在非空连接线方案，两人的账目都保持为 $0$。
- 每种连接线方案单独统计，不会影响其他方案的染色规则。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
2 2 2
```

**输出：**

```text
14
```

## 样例 1 解释

共有四条可设置的连接线。

选一条连接线的方案有 $4$ 种，每种有 $8$ 种合法染色；选三条的方案有 $4$ 种，每种有 $2$ 种合法染色。因此甲的账目为 $4\times8+4\times2=40$。

选两条连接线的方案有 $6$ 种，每种有 $4$ 种合法染色；四条全部选中的方案有 $1$ 种，有 $2$ 种合法染色。因此乙的账目为 $6\times4+2=26$。

账目之差为 $40-26=14$。

## 样例 2

**输入：**

```text
0 7 4
```

**输出：**

```text
0
```

## 样例 2 解释

左区没有展台，因此没有任何可以设置的连接线。空连接线方案不参与记账，甲和乙的账目都为 $0$。
