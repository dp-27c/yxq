# 题目 4：清空货架

## 题目描述

仓库保存着 $k$ 类零件，第 $i$ 类零件每件的重量为 $c_i$。同一类零件彼此不可区分，不同类零件即使重量相同，也仍然按类别区分。

仓库要独立处理 $q$ 份装箱请求。每份请求给出目标重量 $S$、一个整数 $r$，以及各类零件的当前库存 $d_1,d_2,\ldots,d_k$。

对于这份请求，需要选择一个非负整数向量 $(x_1,x_2,\ldots,x_k)$，其中 $x_i$ 表示装入箱子的第 $i$ 类零件数量，并满足：

- $0\le x_i\le d_i$；
- 箱中零件的总重量恰好为 $S$，即 $\sum_{i=1}^k c_ix_i=S$；
- 恰好有 $r$ 类零件在装箱后没有剩余，即恰好有 $r$ 个下标满足 $x_i=d_i$。

特别地，若某类零件的库存一开始就是 $0$，那么它在装箱后也没有剩余，必须计入这 $r$ 类之中。

两种装箱方案不同，当且仅当至少一类零件的选取数量不同。装箱顺序不影响方案是否相同。

请对每份请求计算合法装箱方案的数量，答案对 $10^9+7$ 取模。

## 输入格式

第一行包含两个整数 $k,q$。

第二行包含 $k$ 个整数 $c_1,c_2,\ldots,c_k$。

接下来 $q$ 行，每行包含 $k+2$ 个整数 $S,r,d_1,d_2,\ldots,d_k$，描述一份请求。

## 输出格式

输出 $q$ 行，每行包含一个整数，表示对应请求的合法方案数对 $10^9+7$ 取模后的结果。

## 数据范围与约定

- $1\le k\le6$，$1\le q\le10^4$。
- $1\le c_i\le2\times10^5$。
- 每份请求满足 $0\le S\le2\times10^5$，$0\le r\le k$，$0\le d_i\le10^9$。
- 每份请求都使用该行给出的库存独立计算，不会消耗其他请求中的库存。
- 重量相同但类别不同的零件不能合并为同一类。
- 允许一个零件都不选；它是否为合法方案，仍需满足目标重量和没有剩余的类别数量要求。
- 若没有合法方案，输出 $0$。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
3 4
1 2 3
5 1 2 2 1
6 1 2 2 1
6 2 2 2 1
9 3 2 2 1
```

**输出：**

```text
2
1
1
1
```

## 样例 1 解释

第一份请求的两种合法方案为 $(0,1,1)$ 和 $(1,2,0)$，总重量均为 $5$，且分别只有第 $3$ 类、第 $2$ 类零件没有剩余。

第二份请求只有方案 $(1,1,1)$；第三份请求只有方案 $(2,2,0)$。两者的总重量均为 $6$，但没有剩余的类别数量分别为 $1$ 和 $2$。

第四份请求要求三类零件都没有剩余，只能选择 $(2,2,1)$，总重量恰好为 $9$。

## 样例 2

**输入：**

```text
3 3
1 2 3
0 2 0 2 0
0 0 0 2 0
4 3 0 2 0
```

**输出：**

```text
1
0
1
```

## 样例 2 解释

前两份请求的目标重量为 $0$，唯一可能的选取向量是 $(0,0,0)$。第 $1,3$ 类库存原本就为空，因此恰好有两类没有剩余，这个向量只满足第一份请求。

第三份请求可以选择 $(0,2,0)$，总重量为 $4$，装箱后三类零件都没有剩余。
