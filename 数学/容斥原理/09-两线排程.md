# 题目 9：两线排程

## 题目描述

一座工厂有两条生产线。第一条生产线上有 $a$ 项任务，编号为 $1,2,\ldots,a$；第二条生产线上有 $b$ 项任务，编号为 $a+1,a+2,\ldots,a+b$。

工厂准备为这些任务制定依赖关系。对于分属两条生产线的任意一对任务 $u,v$，必须且只能选择以下三种安排之一：

- 不设置它们之间的直接依赖关系。
- 规定任务 $u$ 必须在任务 $v$ 之前完成，记为 $u\to v$。
- 规定任务 $v$ 必须在任务 $u$ 之前完成，记为 $v\to u$。

同一条生产线上的两个任务之间不能设置直接依赖关系。依赖关系可以通过其他任务间接传递。

一份依赖方案是合法的，当且仅当可以将全部 $a+b$ 项任务排成一个执行顺序，使每条直接依赖关系 $u\to v$ 都满足 $u$ 出现在 $v$ 之前。

请计算有多少份合法的依赖方案，答案对 $998244353$ 取模。

只要某一对任务之间的直接安排不同，就视为不同方案。即使两份方案允许的执行顺序完全相同，它们也可能是不同方案。反过来，同一份依赖方案即使允许多种执行顺序，也只能计数一次。

## 输入格式

输入一行，包含两个整数 $a,b$，分别表示两条生产线上的任务数量。

## 输出格式

输出一个整数，表示合法依赖方案的数量对 $998244353$ 取模后的结果。

## 数据范围与约定

- $0\le a,b\le70$，$a+b\ge1$。
- 所有任务均按编号区分。
- 一条生产线可以没有任务。
- 对于分属不同生产线的一对任务，不能同时设置两个方向的直接依赖关系。
- 不允许任务依赖自身，也不设置重复的直接依赖关系。
- 不要求所有任务之间存在直接或间接依赖。
- 只统计依赖方案，不统计执行顺序或执行时间。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
2 2
```

**输出：**

```text
79
```

## 样例 1 解释

四对分属不同生产线的任务各有三种直接安排，共有 $81$ 份方案。

其中，包含 $1\to3\to2\to4\to1$ 的方案，以及将这四条依赖全部反向的方案，都无法安排执行顺序。这是仅有的两份不合法方案，因此答案为 $79$。

例如，不设置任何依赖关系的方案有很多种可行执行顺序，但该方案仍然只计数一次。

## 样例 2

**输入：**

```text
0 4
```

**输出：**

```text
1
```

## 样例 2 解释

所有任务都属于第二条生产线，因此不能设置任何直接依赖关系。唯一的方案是空的依赖关系集，它是合法的。
