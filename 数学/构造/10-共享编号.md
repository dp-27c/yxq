# 题目 10：共享编号

**预估 CF Rating：2200（主观估计，非官方评级）**

## 题目描述

有 $p^2$ 个小组，需要参加 $p+1$ 轮活动。每一轮中，每个小组都要获得一个 $0$ 到 $p-1$ 之间的整数编号；不同小组可以在同一轮获得相同编号。

前两轮的编号已经确定。小组 $i$ 在第一轮的编号为 $a_i$，第二轮的编号为 $b_i$。输入保证，所有 $0\le a,b<p$ 的有序对 $(a,b)$ 在这 $p^2$ 个小组中各出现恰好一次。

你需要补全所有小组的编号表，使任意两个不同小组都恰好在一轮活动中获得相同编号。

更准确地说，若小组 $i$ 在第 $j$ 轮的编号为 $c_{i,j}$，则必须满足

$$
c_{i,1}=a_i,\qquad c_{i,2}=b_i,
$$

并且对任意 $i\ne i'$，满足 $c_{i,j}=c_{i',j}$ 的轮次 $j$ 恰好有一个。

## 输入格式

第一行包含一个整数 $p$。

接下来 $p^2$ 行，第 $i$ 行包含两个整数 $a_i,b_i$，表示小组 $i$ 的前两轮编号。

## 输出格式

如果不存在满足条件的编号表，输出一行 `NO`。

否则，第一行输出 `YES`，接下来输出 $p^2$ 行，每行包含 $p+1$ 个整数。第 $i$ 行依次为小组 $i$ 在各轮活动中的编号 $c_{i,1},c_{i,2},\ldots,c_{i,p+1}$。

每个编号都必须在 $0$ 到 $p-1$ 之间。存在多个合法答案时，输出任意一个均可。

## 数据范围与约定

- $2\le p\le47$，输入保证 $p$ 是素数。
- $0\le a_i,b_i<p$。
- $p^2$ 个输入有序对互不相同，且包含范围内的所有有序对。
- 小组编号由输入顺序确定，输出中不得调整小组顺序。
- 两个小组只有在同一轮取得相同编号时，才计为一次编号相同；不同轮次之间不进行比较。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
2
0 0
1 1
0 1
1 0
```

**输出：**

```text
YES
0 0 0
1 1 0
0 1 1
1 0 1
```

## 样例 1 解释

前两列与输入一致。小组 $1$ 与小组 $2$ 只在第三轮编号相同，小组 $1$ 与小组 $3$ 只在第一轮编号相同，小组 $1$ 与小组 $4$ 只在第二轮编号相同。

另外三对小组也各自恰好在一轮编号相同，因此该表合法。

## 样例 2

**输入：**

```text
3
0 0
0 1
0 2
1 0
1 1
1 2
2 0
2 1
2 2
```

**输出：**

```text
YES
0 0 0 0
0 1 1 2
0 2 2 1
1 0 1 1
1 1 2 0
1 2 0 2
2 0 2 2
2 1 0 1
2 2 1 0
```

## 样例 2 解释

所有编号均在 $0$ 到 $2$ 之间，且前两轮编号没有改变。

例如，小组 $1$ 与小组 $5$ 只在第四轮编号相同，小组 $2$ 与小组 $6$ 也只在第四轮编号相同，小组 $4$ 与小组 $9$ 只在第三轮编号相同。检查其余小组对，也都满足恰好一轮编号相同的要求。
