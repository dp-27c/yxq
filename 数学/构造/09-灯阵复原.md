# 题目 9：灯阵复原

**预估 CF Rating：2200（主观估计，非官方评级）**

## 题目描述

有一个 $n$ 行 $m$ 列的灯阵，每盏灯的状态为 $0$ 或 $1$。给定当前状态矩阵 $A$ 和目标状态矩阵 $B$，你希望通过若干次操作将灯阵变成目标状态。

一次操作需要选择两个不同行 $r_1,r_2$ 和两个不同列 $c_1,c_2$。选中的四盏灯必须恰有两盏处于状态 $1$，而且这两盏灯既不在同一行，也不在同一列。随后，将这四盏灯的状态全部翻转，即 $0$ 变成 $1$，$1$ 变成 $0$。

每次操作能否执行，都根据该次操作开始前的灯阵状态判断。选择的行或列不必相邻。

请输出一个操作次数不超过 $nm$ 的合法操作序列，使最终状态恰好等于 $B$。如果不存在满足上述要求的操作序列，输出 `NO`。

## 输入格式

第一行包含两个整数 $n,m$。

接下来 $n$ 行，每行包含一个长度为 $m$、仅由字符 `0` 和 `1` 组成的字符串，依次表示矩阵 $A$ 的各行。

再接下来 $n$ 行，以相同格式给出矩阵 $B$。

## 输出格式

如果无解，输出一行 `NO`。

否则，第一行输出 `YES`，第二行输出操作次数 $t$。接下来 $t$ 行，每行输出四个整数 $r_1,r_2,c_1,c_2$，表示按顺序执行的一次操作。

必须满足 $0\le t\le nm$。存在多个合法操作序列时，输出任意一个均可，不要求操作次数最少。

## 数据范围与约定

- $1\le n,m\le40$。
- 两个矩阵的所有元素均为 $0$ 或 $1$。
- 输出的每次操作必须满足 $1\le r_1,r_2\le n$、$r_1\ne r_2$，以及 $1\le c_1,c_2\le m$、$c_1\ne c_2$。
- 行列编号均从 $1$ 开始，不要求 $r_1<r_2$ 或 $c_1<c_2$。
- 允许不进行任何操作。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
3 3
100
010
001
010
001
100
```

**输出：**

```text
YES
2
1 3 1 3
1 2 2 3
```

## 样例 1 解释

第一次操作选择第 $1,3$ 行和第 $1,3$ 列，选中的两个状态为 $1$ 的位置是 $(1,1)$ 和 $(3,3)$，因此操作合法。操作后灯阵的三行依次为 `001`、`010`、`100`。

第二次操作选择第 $1,2$ 行和第 $2,3$ 列，同样满足操作条件。完成后灯阵恰好等于目标矩阵。总共使用两次操作，没有超过 $nm=9$ 的限制。

## 样例 2

**输入：**

```text
1 2
10
01
```

**输出：**

```text
NO
```

## 样例 2 解释

灯阵只有一行，无法选择两个不同行执行操作。当前状态又与目标状态不同，因此无解。
