# 题目 1：道路验收

**预估 CF Rating：1500（主观估计，非官方评级）**

## 题目描述

一片区域中有 $n$ 个站点，编号为 $1,2,\ldots,n$。你需要在站点之间修建双向道路，使整个道路网络是一棵树，即所有站点互相连通，且不存在环。

第 $i$ 个站点有一个验收标记 $p_i$：

- 若 $p_i=0$，与该站点直接相连的道路数量必须为偶数。
- 若 $p_i=1$，与该站点直接相连的道路数量必须为奇数。

请构造一个满足全部验收要求的道路网络。如果不存在，报告无解。

## 输入格式

第一行包含一个整数 $n$。

第二行包含 $n$ 个整数 $p_1,p_2,\ldots,p_n$。

## 输出格式

如果无解，输出一行 `NO`。

否则，第一行输出 `YES`，随后输出 $n-1$ 行。每行包含两个整数 $u,v$，表示在站点 $u,v$ 之间修建一条双向道路。

如果存在多个合法方案，可以输出任意一个。$n=1$ 时，合法方案只需输出 `YES`，后面没有道路。

## 数据范围与约定

- $1\le n\le2\times10^5$。
- $p_i\in\{0,1\}$。
- 道路的两个端点必须不同，同一对站点之间不能重复修建道路。
- 每条道路在它的两个端点处各计入一次道路数量。
- $0$ 是偶数。只有一个站点且没有道路的网络也视为一棵树。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
6
1 0 1 0 1 1
```

**输出：**

```text
YES
1 2
2 4
4 3
1 5
1 6
```

## 样例 1 解释

站点 $1,2,3,4,5,6$ 直接相连的道路数量分别为 $3,2,1,2,1,1$，满足全部标记要求。给出的五条道路连接了所有站点，且没有形成环。

## 样例 2

**输入：**

```text
3
0 0 0
```

**输出：**

```text
NO
```

## 样例 2 解释

三个站点组成的树必然是一条包含两条道路的链，两端的站点各连接一条道路，无法满足所有站点都要求偶数条道路的条件。
