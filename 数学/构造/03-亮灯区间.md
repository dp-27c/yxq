# 题目 3：亮灯区间

**预估 CF Rating：1700（主观估计，非官方评级）**

## 题目描述

一排共有 $n$ 盏灯，你需要决定每盏灯的初始状态。用长度为 $n$ 的二进制字符串 $s$ 表示这些状态：$s_i=1$ 表示第 $i$ 盏灯亮着，$s_i=0$ 表示熄灭。

一个区间由两个端点 $l,r$ 确定，满足 $1\le l\le r\le n$。若该区间中亮着的灯的数量为奇数，则称这个区间为亮灯区间。

给定 $n,m,K$，请构造一个字符串，使亮着的灯恰有 $m$ 盏，且亮灯区间的数量恰好为 $K$。如果不存在，报告无解。

## 输入格式

第一行包含三个整数 $n,m,K$。

## 输出格式

如果无解，输出一行 `NO`。

否则，第一行输出 `YES`，第二行输出一个长度为 $n$、仅包含字符 `0` 和 `1` 的字符串。

如果存在多个合法方案，可以输出任意一个。

## 数据范围与约定

- $1\le n\le2\times10^5$。
- $0\le m\le n$。
- $0\le K\le n(n+1)/2$。
- 区间必须非空。两个区间不同，当且仅当它们的左端点或右端点不同。
- $K$ 表示区间的实际数量，不取模，可能超出 $32$ 位有符号整数范围。
- 输出字符串中不能插入空格。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
5 3 8
```

**输出：**

```text
YES
11001
```

## 样例 1 解释

第 $1,2,5$ 盏灯亮着，共有三盏。

亮灯区间恰好为 $[1,1]$、$[1,5]$、$[2,2]$、$[2,3]$、$[2,4]$、$[3,5]$、$[4,5]$ 和 $[5,5]$，共八个，因此给出的输出合法。

## 样例 2

**输入：**

```text
4 3 4
```

**输出：**

```text
NO
```

## 样例 2 解释

长度为四且恰有三个字符 `1` 的字符串只有 `1110`、`1101`、`1011` 和 `0111`。它们各自都有六个亮灯区间，无法满足要求的四个。
