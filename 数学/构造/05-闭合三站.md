# 题目 5：闭合三站

**预估 CF Rating：1900（主观估计，非官方评级）**

模型参考：[Codeforces 233C — Cycles](https://codeforces.com/problemset/problem/233/C)。本题为独立编写的中文训练版本，调整了数据范围、连通要求和输出格式，样例另行编写。

## 题目描述

你需要设计一张交通网络，包含若干个站点和连接站点的双向线路。

网络中不能有连接同一站点的线路，任意两个不同站点之间至多有一条线路。任意两个站点之间都必须能够沿线路相互到达。

如果三个不同站点两两之间都有线路，则称它们组成一个闭合三站组合。组合只由三个站点的集合确定，不区分选择顺序。

给定非负整数 $K$，请构造一张不超过 $200$ 个站点的网络，使其恰好包含 $K$ 个闭合三站组合。

## 输入格式

输入一行，包含一个整数 $K$。

## 输出格式

第一行输出两个整数 $n,m$，分别表示站点数和线路数。站点编号为 $1,2,\ldots,n$。

接下来 $m$ 行，每行输出两个整数 $u_i,v_i$，表示一条连接站点 $u_i,v_i$ 的双向线路。

输出必须满足题目中的全部要求。若有多种合法网络，输出任意一种即可。

## 数据范围与约定

- $0\le K\le10^6$。
- 输出须满足 $1\le n\le200$，$0\le m\le n(n-1)/2$。
- 每条线路须满足 $1\le u_i,v_i\le n$ 且 $u_i\ne v_i$，不能重复输出同一条无向线路。
- 网络必须连通；只有一个站点、没有线路的网络也视为连通。
- 数据范围内的每个 $K$ 都存在合法构造，无需输出无解标记。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
3
```

**输出：**

```text
5 7
1 2
1 3
2 3
1 4
2 4
1 5
2 5
```

## 样例 1 解释

该网络连通，且没有自环或重复线路。

恰好有三个闭合三站组合：$\{1,2,3\}$、$\{1,2,4\}$ 和 $\{1,2,5\}$。其余三个站点的集合均不满足两两之间都有线路，因此给出的输出合法。

## 样例 2

**输入：**

```text
0
```

**输出：**

```text
1 0
```

## 样例 2 解释

网络只有一个站点，按约定视为连通。由于不存在三个不同的站点，闭合三站组合的数量为 $0$。
