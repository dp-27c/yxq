# 题目 6：逐层接入

**预估 CF Rating：2000（主观估计，非官方评级）**

模型参考：[Codeforces 1311E — Construct the Binary Tree](https://codeforces.com/problemset/problem/1311/E)。本题为独立编写的中文训练版本，扩大了数据范围，并包含单点树及零深度和的边界，样例另行编写。

## 题目描述

有 $n$ 台设备，编号为 $1,2,\ldots,n$。你需要将它们连接成一棵以设备 $1$ 为根的树。

根以外的每台设备恰好有一个直接上级。每台设备至多可以作为两台设备的直接上级。

设备 $i$ 的接入层数定义为它到根的路径所经过的边数，记为 $d_i$。因此 $d_1=0$。

给定整数 $D$，请构造一棵满足上述要求的树，使得

$$
\sum_{i=1}^{n}d_i=D.
$$

如果不存在这样的树，请报告无解。

## 输入格式

输入一行，包含两个整数 $n,D$。

## 输出格式

如果无解，输出一行 `NO`。

否则，第一行输出 `YES`。第二行输出 $n-1$ 个整数 $p_2,p_3,\ldots,p_n$，其中 $p_i$ 表示设备 $i$ 的直接上级。

这些直接上级关系必须形成一棵以设备 $1$ 为根的树，每台设备的直接下级数量至多为 $2$，且接入层数之和恰好为 $D$。

当 $n=1$ 时，输出 `YES` 后无需输出第二行。若有多种合法构造，输出任意一种即可。

## 数据范围与约定

- $1\le n\le2\times10^5$。
- $0\le D\le n(n-1)/2$。
- 对每个 $2\le i\le n$，输出的 $p_i$ 必须满足 $1\le p_i\le n$ 且 $p_i\ne i$。
- 不要求设备编号按层数排列，也不要求直接上级的编号小于直接下级。
- 每个非根设备沿直接上级关系最终都必须到达设备 $1$。
- $D$ 可能超过 $32$ 位有符号整数范围。
- 输入仅包含一组数据。

## 样例 1

**输入：**

```text
6 10
```

**输出：**

```text
YES
1 1 2 4 4
```

## 样例 1 解释

设备 $1$ 的直接下级为 $2,3$，设备 $2$ 的直接下级为 $4$，设备 $4$ 的直接下级为 $5,6$。每台设备都没有超过两个直接下级。

设备 $1$ 到 $6$ 的接入层数依次为 $0,1,1,2,3,3$，总和为 $10$，所以给出的输出合法。

## 样例 2

**输入：**

```text
4 2
```

**输出：**

```text
NO
```

## 样例 2 解释

除根以外还有三台设备，它们的接入层数都至少为 $1$，因此接入层数之和不可能为 $2$。

## 样例 3

**输入：**

```text
1 0
```

**输出：**

```text
YES
```

## 样例 3 解释

唯一的设备就是根，它的接入层数为 $0$，无需输出直接上级。
